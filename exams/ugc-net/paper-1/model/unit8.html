    Model Questions — Unit 8: Information and Communication Technology

    UGC NET Paper I (General Paper) · 50 questions · Click "Show Answer" for the worked solution

    About this set

    Abbreviations and terminology, bits and bytes, the internet and the web, intranet and extranet, e-mail, audio and video conferencing, digital initiatives in higher education, and ICT in governance.

    These are model questions written for practice at the standard of the paper; they are not questions from a past paper. Try each one before opening the answer. Every answer gives the working and a link to the section of the Unit 8 notes that teaches it.

    The questions

    Q1. Match the abbreviation in List I with what it does in List II.
    List IList II
    (a) DNS(i) Transfers files between computers
    (b) SMTP(ii) Carries web pages over an encrypted connection
    (c) FTP(iii) Translates domain names into IP addresses
    (d) HTTPS(iv) Sends e-mail
    1. (a)-(iii), (b)-(i), (c)-(iv), (d)-(ii)
    2. (a)-(iii), (b)-(iv), (c)-(i), (d)-(ii)
    3. (a)-(iv), (b)-(iii), (c)-(i), (d)-(ii)
    4. (a)-(iii), (b)-(iv), (c)-(ii), (d)-(i)
    Show Answer

    Answer: (B) (a)-(iii), (b)-(iv), (c)-(i), (d)-(ii).

    The Domain Name System turns a name such as ugc.gov.in into an IP address; the Simple Mail Transfer Protocol sends mail; the File Transfer Protocol moves files; HTTPS is HTTP made secure by encryption.

    Read this in the notes: Unit 8, ICT: General Abbreviations and Terminology

    Q2. The number of bits in 2 KB, taking 1 KB as 1,024 bytes, is:
    1. 2,048
    2. 8,192
    3. 16,000
    4. 16,384
    Show Answer

    Answer: (D) 16,384.

    $2\times1{,}024$ bytes $=2{,}048$ bytes, and each byte is 8 bits: $2{,}048\times8=16{,}384$ bits. (2,048 is the number of bytes; 16,000 takes a kilobyte as 1,000 bytes.)

    Read this in the notes: Unit 8, ICT: General Abbreviations and Terminology

    Q3. The decimal equivalent of the binary number 11010 is:
    1. 26
    2. 22
    3. 25
    4. 52
    Show Answer

    Answer: (A) 26.

    The places of a binary number, from the right, are worth 1, 2, 4, 8, 16. So 11010 is $1\times16+1\times8+0\times4+1\times2+0\times1=26$.

    Read this in the notes: Unit 8, ICT: General Abbreviations and Terminology

    Q4. The binary equivalent of the decimal number 45 is:
    1. 101011
    2. 110101
    3. 101101
    4. 100101
    Show Answer

    Answer: (C) 101101.

    $45=32+8+4+1$, so the digits for $32,16,8,4,2,1$ are $1,0,1,1,0,1$: 101101. Check: $32+0+8+4+0+1=45$.

    Read this in the notes: Unit 8, ICT: General Abbreviations and Terminology

    Q5. Arrange the following units of storage in increasing order of size: (1) Gigabyte, (2) Kilobyte, (3) Terabyte, (4) Megabyte, (5) Byte.
    1. 5, 2, 1, 4, 3
    2. 5, 2, 4, 1, 3
    3. 2, 5, 4, 1, 3
    4. 5, 4, 2, 1, 3
    Show Answer

    Answer: (B) 5, 2, 4, 1, 3.

    Byte, kilobyte, megabyte, gigabyte, terabyte: each is 1,024 times the one before it in computing usage.

    Read this in the notes: Unit 8, ICT: General Abbreviations and Terminology

    Q6. A file of 50 MB is downloaded over a connection whose speed is 100 Mbps. Ignoring overheads, the download takes about:
    1. 0.5 second
    2. 2 seconds
    3. 8 seconds
    4. 4 seconds
    Show Answer

    Answer: (D) 4 seconds.

    Speeds are quoted in bits per second and file sizes in bytes. $100$ Mbps $=\dfrac{100}{8}=12.5$ MB per second, so 50 MB takes $\dfrac{50}{12.5}=4$ seconds. Forgetting the factor 8 gives half a second.

    Read this in the notes: Unit 8, ICT: General Abbreviations and Terminology

    1. I, II and III only
    2. I and II only
    3. II, III and IV only

    Answer: (A) I, II and III only.

    Q10. In the address https://www.ugc.gov.in/page.html, the parts ‘https’, ‘www.ugc.gov.in’ and ‘page.html’ are, respectively:

    Q25. Which e-mail protocol keeps messages on the server and synchronised across a phone and a laptop?
    1. SMTP
    2. IMAP
    3. POP3
    4. FTP
    Show Answer

    Answer: (B) IMAP.

    IMAP leaves mail on the server and keeps every device in step. POP3 usually downloads mail to one device and removes it from the server. SMTP is used for sending.

    Read this in the notes: Unit 8, E-mail

    1. (a)-(iii), (b)-(iv), (c)-(i), (d)-(ii)
    2. (a)-(iv), (b)-(iii), (c)-(i), (d)-(ii)
    3. (a)-(iii), (b)-(i), (c)-(iv), (d)-(ii)
    4. (a)-(iii), (b)-(iv), (c)-(ii), (d)-(i)
    Show Answer

    Answer: (A) (a)-(iii), (b)-(iv), (c)-(i), (d)-(ii).

    DigiLocker holds documents; UMANG (Unified Mobile Application for New-age Governance) gathers many services in one app; the Unified Payments Interface, from the National Payments Corporation of India, makes instant payments; Aadhaar is the identity.

    Q47. Given below are two statements, one labelled Assertion (A) and the other Reason (R).Assertion (A): Online tendering reduces corruption in public procurement.Reason (R): When bids are submitted and opened on a public portal, there is less room for discretion and more transparency.Choose the correct answer.
    1. Both (A) and (R) are true and (R) is the correct explanation of (A)
    2. Both (A) and (R) are true but (R) is not the correct explanation of (A)
    3. (A) is true but (R) is false
    4. (A) is false but (R) is true
    Show Answer

    Answer: (A) Both (A) and (R) are true and (R) is the correct explanation of (A).

    Corruption thrives on discretion and secrecy; a portal on which every bid is recorded and opened removes both. Both statements are true and (R) is the reason.

    Q48. Which of the following is a challenge, and not a benefit, of e-governance?
    1. Services available at any hour
    2. Greater transparency
    3. Faster delivery
    4. The digital divide
    Show Answer

    Answer: (D) The digital divide.

    The digital divide is the gap between those who have access to devices, connectivity and digital skills and those who do not. Privacy, data protection and cyber security are the other main challenges.

    4. I, II, III and IV
    Show Answer
