Practical Course — 7 Experiments

Semester V, Course 11 (Practical) — 2 hrs/week, Credit 1. Each experiment is set out in the standard lab-record format: 1. Problem, 2. Aim, 3. Procedure (with formula/R script and a blank working table), 4. Calculation, 5. Result. Labs are done in the Computer Lab (≥ 4 hrs/month) using R.

How to use this manual: In the lab, type the R script from the Procedure, copy the blank working table into your record book and fill it with the values the console returns (shown in the Calculation section). The Result states the decision and its interpretation. Use built-in datasets (iris, mtcars, airquality, ToothGrowth, sleep) or a CSV from the UCI ML Repository.

List of Practical Experiments (Official Syllabus)

  1. Data Import and Preprocessing — import dataset (e.g., iris), handle missing values, basic sub-setting.
  2. Descriptive Statistics Computation — mean, variance, skewness; interpret results.
  3. Frequency Analysis — contingency tables and chi-square tests on categorical data.
  4. Basic Visualizations — histograms and boxplots to assess data normality.
  5. Hypothesis Testing — t-tests and ANOVA on experimental data, reporting p-values.
  6. Non-Parametric Tests — Wilcoxon tests; compare with parametric alternatives.
  7. Linear Regression Modeling — fit a simple linear model, plot residuals, predict new values.

Experiment 1 — Data Import & Preprocessing

1. Problem

Import the built-in airquality dataset (153 observations, 6 variables), examine its structure, count and handle the missing values, and create subsets.

2. Aim

To read a dataset into R, inspect it, deal with missing values (drop or impute), and perform sub-setting.

3. Procedure

  1. Load the data and inspect it with str().
  2. Count missing values per column with colSums(is.na(...)).
  3. Drop rows with any NA (na.omit) and/or impute the mean.
  4. Subset rows meeting a condition and save the cleaned file.
data(airquality)
str(airquality)                 # 153 obs of 6 vars; NAs in Ozone and Solar.R
colSums(is.na(airquality))      # count NAs per column
clean <- na.omit(airquality)    # drop rows with any NA
nrow(clean)
airquality$Ozone[is.na(airquality$Ozone)] <- mean(airquality$Ozone, na.rm = TRUE)  # mean-impute
hot <- subset(airquality, Temp > 80)   # subset
nrow(hot)
write.csv(clean, "airquality_clean.csv", row.names = FALSE)

Experiment 2 — Descriptive Statistics

1. Problem

For iris$Sepal.Length (150 observations), compute the standard descriptive statistics and the shape measures (skewness, kurtosis), then interpret.

2. Aim

To summarise a numeric variable in R with measures of location, dispersion and shape.

3. Procedure

  1. Compute mean, median, var, sd, range, IQR.
  2. Load moments for skewness() and kurtosis().
  3. Optionally use psych::describe() for a full report.
\[ \bar x = \frac{\sum x}{n}, \quad s^2 = \frac{\sum(x-\bar x)^2}{n-1}, \quad \sqrt{b_1} = \frac{m_3}{m_2^{3/2}}, \quad b_2 = \frac{m_4}{m_2^{2}} \]
data(iris); x <- iris$Sepal.Length
mean(x); median(x); var(x); sd(x); range(x); IQR(x)
library(moments); skewness(x); kurtosis(x)

Experiment 3 — Frequency Analysis & Chi-Square

1. Problem

Cross-classify iris flowers by Species and by whether the petal is "Long" (Petal.Length > 4) or "Short", and test whether Species and petal category are independent.

2. Aim

To build a contingency table and apply the chi-square test of independence (and, as a variant, a goodness-of-fit test).

3. Procedure

  1. Create the categorical variable and the two-way table with table().
  2. Apply chisq.test() and read \(\chi^2\), df and the p-value.
  3. For goodness of fit, tabulate simulated die rolls and test against a uniform expectation.
\[ \chi^2 = \sum \frac{(O-E)^2}{E}, \qquad df = (r-1)(c-1) \]
big <- ifelse(iris$Petal.Length > 4, "Long", "Short")
tbl <- table(iris$Species, big); tbl
chisq.test(tbl)
# Goodness of fit
set.seed(7); rolls <- sample(1:6, 120, replace = TRUE)
chisq.test(table(rolls))        # expected: uniform 1/6 each

Experiment 4 — Basic Visualizations & Normality

1. Problem

Visualise iris variables with histograms and boxplots, and assess the normality of Sepal.Length using a Q-Q plot and the Shapiro–Wilk test.

2. Aim

To produce diagnostic plots and a formal normality test to judge whether a variable is normally distributed.

3. Procedure

  1. Draw a histogram with a fitted normal curve and a species boxplot.
  2. Draw a Q-Q plot and add the reference line.
  3. Run shapiro.test() and record the p-value.
par(mfrow = c(1, 2))
hist(iris$Sepal.Length, breaks = 15, col = "lightblue", freq = FALSE,
     main = "Histogram of Sepal Length", xlab = "Sepal length (cm)")
curve(dnorm(x, mean(iris$Sepal.Length), sd(iris$Sepal.Length)), add = TRUE, col = "red", lwd = 2)
boxplot(Sepal.Length ~ Species, data = iris, notch = TRUE,
        col = c("pink","skyblue","lightgreen"), main = "Sepal Length by Species")
par(mfrow = c(1, 1))
qqnorm(iris$Sepal.Length); qqline(iris$Sepal.Length, col = "red", lwd = 2)
shapiro.test(iris$Sepal.Length)

Experiment 5 — Hypothesis Testing (t-tests & ANOVA)

1. Problem

Carry out (a) a one-sample t-test of \(H_0:\mu = 50\) on ten measurements, (b) a two-sample (Welch) t-test comparing setosa vs versicolor Sepal.Length, (c) a paired t-test on the sleep data, and (d) a one-way ANOVA of Sepal.Length by Species.

2. Aim

To perform parametric tests of means (one-sample, two-sample, paired) and ANOVA in R and report the p-values.

3. Procedure

  1. One-sample: t.test(x, mu = 50).
  2. Two-sample Welch: t.test(setosa, versicolor).
  3. Paired: t.test(extra ~ group, data = sleep, paired = TRUE).
  4. ANOVA: aov(Sepal.Length ~ Species, data = iris) then TukeyHSD.
\[ t = \frac{\bar x - \mu_0}{s/\sqrt n}, \qquad F = \frac{MS_{between}}{MS_{within}} \]
x <- c(48, 52, 49, 53, 51, 47, 55, 50, 49, 52)
t.test(x, mu = 50)
setosa     <- iris$Sepal.Length[iris$Species == "setosa"]
versicolor <- iris$Sepal.Length[iris$Species == "versicolor"]
t.test(setosa, versicolor)
data(sleep); t.test(extra ~ group, data = sleep, paired = TRUE)
summary(aov(Sepal.Length ~ Species, data = iris)); TukeyHSD(aov(Sepal.Length ~ Species, data = iris))

Experiment 6 — Non-Parametric Tests

1. Problem

Repeat the location comparisons of Experiment 5 without the normality assumption: a one-sample Wilcoxon signed-rank test, a paired signed-rank test on sleep, and a Wilcoxon rank-sum (Mann–Whitney) test for setosa vs versicolor; compare the last with its parametric counterpart.

2. Aim

To apply rank-based non-parametric tests and contrast them with the parametric t-tests.

3. Procedure

  1. One-sample signed-rank: wilcox.test(x, mu = 50).
  2. Paired signed-rank: wilcox.test(extra ~ group, data = sleep, paired = TRUE).
  3. Rank-sum: wilcox.test(setosa, versicolor).
  4. Tabulate the t-test and Wilcoxon p-values side by side.
x <- c(48, 52, 49, 53, 51, 47, 55, 50, 49, 52)
wilcox.test(x, mu = 50)                       # V = 28.5, p = 0.511
wilcox.test(extra ~ group, data = sleep, paired = TRUE)
wilcox.test(setosa, versicolor)               # W = 168.5, p = 8.3e-14
data.frame(Test = c("Welch t","Wilcoxon"),
           p = c(t.test(setosa, versicolor)$p.value, wilcox.test(setosa, versicolor)$p.value))

Experiment 7 — Linear Regression Modeling

1. Problem

Using mtcars, model fuel economy (mpg) as a linear function of weight (wt), check the residuals, and predict mpg for weights 2.5, 3.5 and 4.5 (× 1000 lbs).

2. Aim

To fit a simple linear regression, assess it (\(R^2\), residual diagnostics) and forecast with prediction intervals.

3. Procedure

  1. Fit with lm(mpg ~ wt) and read the coefficients and \(R^2\) from summary().
  2. Plot the scatter with the fitted line; run plot(fit) and shapiro.test(resid(fit)).
  3. Predict with predict(fit, newdata, interval = "prediction").
\[ \widehat{mpg} = a + b\cdot wt, \qquad b = \frac{\sum(x-\bar x)(y-\bar y)}{\sum(x-\bar x)^2} \]
data(mtcars); fit <- lm(mpg ~ wt, data = mtcars); summary(fit)
plot(mtcars$wt, mtcars$mpg, pch = 19, col = "navy"); abline(fit, col = "red", lwd = 2)
par(mfrow = c(2, 2)); plot(fit); par(mfrow = c(1, 1))
predict(fit, data.frame(wt = c(2.5, 3.5, 4.5)), interval = "prediction")

Lab Record Format (to be followed for every experiment)

  1. 1. Problem — the dataset and the task.
