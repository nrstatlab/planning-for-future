About this paper. STS-107 is a 2-credit practical examined in two sections — Section A conventional (by hand) and Section B using R. Both are covered here: each experiment gives the manual procedure worked through with real arithmetic, then the R that does the same job. The R basics are assumed and are taught in Computational Statistics and R Programming.

Objectives

  1. Knowing the manual procedures and also their implementation using R.
  2. Generation of random samples from any distribution.
  3. Identifying an appropriate probability distribution for the given data.
  4. Fitting and testing the probability distribution.
  5. Drawing the probability distribution curves and stating the nature of the distributional curve and its properties for the given data sets.

Practical 1 — Uniform Random Numbers

THE CONVENTIONAL METHOD

A linear congruential generator produces integers by

\[ x_{i+1} = (a x_i + c) \bmod m, \qquad u_{i+1} = \frac{x_{i+1}}{m}, \]

starting from a seed \(x_0\). The \(u_i\) lie in \([0,1)\) and, for well chosen \(a, c, m\), pass the usual tests of uniformity and independence.

Worked by hand with \(a = 5\), \(c = 3\), \(m = 16\), \(x_0 = 7\):

\[ \begin{aligned} x_1 &= (5 \times 7 + 3) \bmod 16 = 38 \bmod 16 = 6, && u_1 = 6/16 = 0.3750 \\ x_2 &= (5 \times 6 + 3) \bmod 16 = 33 \bmod 16 = 1, && u_2 = 1/16 = 0.0625 \\ x_3 &= (5 \times 1 + 3) \bmod 16 = 8 \bmod 16 = 8, && u_3 = 8/16 = 0.5000 \\ x_4 &= (5 \times 8 + 3) \bmod 16 = 43 \bmod 16 = 11, && u_4 = 11/16 = 0.6875 \\ x_5 &= (5 \times 11 + 3) \bmod 16 = 58 \bmod 16 = 10, && u_5 = 10/16 = 0.6250 \end{aligned} \]

The modulus bounds the period at \(m = 16\), so this toy generator repeats quickly; real ones use \(m\) of the order of \(2^{31}\) or more. Interpretation: the numbers are not random at all — they are a completely determined sequence that behaves like one, which is why the term is pseudo-random and why the seed reproduces a run exactly.

IN R 
set.seed(2025)                 # reproducibility: same seed, same sample
u <- runif(1000)
mean(u); var(u)                # compare with 0.5 and 1/12 = 0.08333
hist(u, breaks = 20, freq = FALSE, main = "1000 uniform variates")
abline(h = 1, col = "red", lwd = 2)      # the U(0,1) density
ks.test(u, "punif")            # formal test of uniformity

Practical 2 — Discrete Variates by Inverse Transform

THE METHOD

For a discrete variable with cumulative probabilities \(F(0) \le F(1) \le \cdots\), draw \(u \sim U(0,1)\) and return the smallest \(x\) with \(u \le F(x)\). The value \(x\) is then returned with probability \(F(x) - F(x-1) = P(X = x)\), which is exactly what is wanted.

Worked by hand, Poisson\((\lambda = 1.5)\). First build the table:

\(x\)\(P(X = x)\)\(F(x)\)
00.2231300.223130
10.3346950.557825
20.2510210.808847
30.1255110.934358
40.0470670.981424
50.0141200.995544

Then read each \(u\) against the last column:

\[ \begin{aligned} u = 0.3750 &: \ 0.223130 < 0.3750 \le 0.557825 &&\Rightarrow\ x = 1 \\ u = 0.0625 &: \ 0.0625 \le 0.223130 &&\Rightarrow\ x = 0 \\ u = 0.5000 &: \ 0.223130 < 0.5000 \le 0.557825 &&\Rightarrow\ x = 1 \\ u = 0.6875 &: \ 0.557825 < 0.6875 \le 0.808847 &&\Rightarrow\ x = 2 \\ u = 0.6250 &: \ 0.557825 < 0.6250 \le 0.808847 &&\Rightarrow\ x = 2 \end{aligned} \]

giving the sample \(1, 0, 1, 2, 2\).

Binomial by a different route. A Bin\((n,p)\) variate can be generated as the count of successes in \(n\) independent Bernoulli trials: draw \(n\) uniforms and count how many fall below \(p\). This is slower than the inverse transform for large \(n\) but needs no cumulative table.

Geometric, in closed form. For the number of failures before the first success, the inverse transform gives \(x = \left\lceil \dfrac{\ln(1-u)}{\ln(1-p)} \right\rceil - 1\), so no table is needed at all.

IN R 
# Built-in generators
rbinom(10, size = 5, prob = 0.4)
rpois(10, lambda = 1.5)
rgeom(10, prob = 0.3)          # counts FAILURES before the first success
rnbinom(10, size = 4, prob = 0.6)

# Inverse transform written out, to show the method rather than hide it
inv_poisson <- function(u, lambda) {
  x <- 0
  cdf <- exp(-lambda)
  while (u > cdf) {
    x <- x + 1
    cdf <- cdf + exp(-lambda) * lambda^x / factorial(x)
  }
  x
}
sapply(c(0.3750, 0.0625, 0.5000, 0.6875, 0.6250), inv_poisson, lambda = 1.5)
#> 1 0 1 2 2      -- matching the table above exactly

Practical 3 — Continuous Variates

EXPONENTIAL, BY INVERSE TRANSFORM

Derivation. \(F(x) = 1 - e^{-\theta x}\). Setting \(u = F(x)\) and solving,

\[ u = 1 - e^{-\theta x} \;\Rightarrow\; e^{-\theta x} = 1 - u \;\Rightarrow\; x = -\frac{\ln(1-u)}{\theta}. \]

Worked by hand with \(\theta = 0.5\):

\(u\)\(1 - u\)\(-\ln(1-u)\)\(x = -\ln(1-u)/0.5\)
0.12730.87270.1361640.272327
0.48200.51800.6577801.315560
0.73910.26091.3436182.687236
0.90520.09482.3559864.711972
0.03610.96390.0367680.073535

Sample mean \(= 1.812126\), against the theoretical \(1/\theta = 2\). Five observations is far too few to expect agreement; the point of the check is that the value is of the right order, not that it matches.

NORMAL, BY BOX–MULLER

The transformation. From two independent uniforms \(u_1, u_2\),

\[ z_1 = \sqrt{-2 \ln u_1}\,\cos(2\pi u_2), \qquad z_2 = \sqrt{-2 \ln u_1}\,\sin(2\pi u_2) \]

are two independent \(N(0,1)\) variates. It is the polar form of the two-dimensional normal: \(-2\ln u_1\) is an Exponential\((\tfrac12)\), which is \(\chi^{2}_{2}\), giving the squared radius, and \(2\pi u_2\) is the angle, uniform on the circle.

Worked by hand with \(u_1 = 0.2740\), \(u_2 = 0.6130\):

\[ \sqrt{-2\ln 0.2740} = \sqrt{2 \times 1.294790} = \sqrt{2.589580} = 1.609116, \] \[ \cos(2\pi \times 0.6130) = -0.758362, \qquad \sin(2\pi \times 0.6130) = -0.651834, \] \[ z_1 = 1.609116 \times (-0.758362) = -1.220292, \qquad z_2 = 1.609116 \times (-0.651834) = -1.048876. \]

A second pair, \(u_1 = 0.8821\), \(u_2 = 0.1094\): \(\sqrt{-2\ln u_1} = 0.500899\), \(\cos = 0.772911\), \(\sin = 0.634515\), giving \(z_1 = 0.387150\) and \(z_2 = 0.317828\).

Others by composition. Gamma\((k, \theta)\) with integer \(k\) is the sum of \(k\) independent Exponential\((\theta)\) variates. Beta\((p,q)\) is \(G_1/(G_1 + G_2)\) with \(G_1 \sim\) Gamma\((p,1)\) and \(G_2 \sim\) Gamma\((q,1)\) independent. Cauchy is \(\tan\!\left[\pi(u - \tfrac12)\right]\), or equivalently the ratio of two independent standard normals.

IN R 
rexp(1000, rate = 0.5)
rnorm(1000, mean = 0, sd = 1)
rgamma(1000, shape = 3, rate = 2)
rbeta(1000, shape1 = 2, shape2 = 5)
rcauchy(1000, location = 0, scale = 1)

# Box-Muller written out, to check against the hand working above
box_muller <- function(u1, u2) {
  r <- sqrt(-2 * log(u1))
  c(r * cos(2 * pi * u2), r * sin(2 * pi * u2))
}
box_muller(0.2740, 0.6130)     #> -1.220292 -1.048876

Practical 4 — Fitting a Discrete Distribution

4a — FITTING A BINOMIAL

Given. Five coins were tossed 100 times and the number of heads recorded:

heads \(x\)012345total
frequency \(f\)2142034228100

Step 1 — estimate \(p\) by the method of moments. Equate the sample mean to \(np\):

\[ \sum f x = 0(2) + 1(14) + 2(20) + 3(34) + 4(22) + 5(8) = 0 + 14 + 40 + 102 + 88 + 40 = 284, \] \[ \bar x = \frac{284}{100} = 2.84, \qquad \hat p = \frac{\bar x}{n} = \frac{2.84}{5} = 0.568, \qquad \hat q = 0.432. \]

Step 2 — expected frequencies. \(E_x = 100 \binom{5}{x} (0.568)^{x}(0.432)^{5-x}\):

\(x\)observed \(O\)expected \(E\)\((O-E)^2/E\)
021.50460.163120
1149.89131.706694
22026.01051.388886
33434.19890.001157
42222.48260.010360
585.91210.737358
total100100.00004.007575

The expected frequencies sum to \(100.000000\), which is the arithmetic check that \(\hat p\) and the binomial probabilities were computed correctly.

Step 3 — the test. Degrees of freedom are \(6 - 1 - 1 = 4\): six cells, less one for the total constraint, less one for the estimated \(p\). So

\[ \chi^{2} = 4.007575 \quad\text{on } 4 \text{ d.f.}, \qquad P\left(\chi^{2}_{4} > 4.007575\right) = 0.404982. \]

Step 4 — conclude. \(0.404982\) is far above \(0.05\) — the tabulated \(5\%\) point is \(9.488\) and the statistic is \(4.008\) — so the binomial model is not rejected.

Interpretation. \(\hat p = 0.568\), not \(0.5\), so the coins are not quite fair, or 100 trials is too few to tell. The goodness-of-fit test answers a different question from "is \(p = 0.5\)": it asks whether the shape is binomial, and it is.

4b — FITTING A POISSON

Given. Accidents per day at a junction over 200 days:

accidents \(x\)012345+total
days \(f\)6070402082200

Step 1 — estimate \(\lambda\). For the Poisson the method of moments and maximum likelihood agree, both giving the sample mean:

\[ \sum f x = 0 + 70 + 80 + 60 + 32 + 10 = 252, \qquad \hat\lambda = \frac{252}{200} = 1.26. \]

Step 2 — expected frequencies. \(E_x = 200\, e^{-1.26}(1.26)^{x}/x!\) for \(x = 0, \ldots, 4\), and the last cell takes the remainder so the totals agree:

\(x\)observed \(O\)expected \(E\)\((O-E)^2/E\)
06056.73080.188392
17071.48080.030677
24045.03290.562482
32018.91380.062377
485.95790.699977
5+21.88380.007169
total200200.00001.551074

Step 3 — the test. \(6 - 1 - 1 = 4\) degrees of freedom, and

\[ \chi^{2} = 1.551074, \qquad P\left(\chi^{2}_{4} > 1.551074\right) = 0.817558. \]

Step 4 — conclude. An excellent fit; there is no evidence against the Poisson.

A caution on the last cell. Its expected frequency is \(1.8838\), below the usual rule of thumb that no expected frequency should fall under 5. Strictly the \(4\) and \(5+\) cells should be pooled, giving \(E = 7.8416\) against \(O = 10\) and \(3\) degrees of freedom. That pooled test gives \(\chi^{2} = 1.438000\) on 3 d.f. with \(P(\chi^{2}_{3} > 1.438000) = 0.696652\), so the conclusion is unchanged; but the pooling should be done and stated rather than passed over.

IN R 
f <- c(2, 14, 20, 34, 22, 8); x <- 0:5
N <- sum(f); phat <- sum(f * x) / (N * 5)
phat                                         #> 0.568
E <- N * dbinom(x, size = 5, prob = phat)
chisq <- sum((f - E)^2 / E)
c(chisq = chisq, df = 4, p = pchisq(chisq, df = 4, lower.tail = FALSE))
#> chisq 4.007575   df 4.000000   p 0.404982

# Poisson
g <- c(60, 70, 40, 20, 8, 2); y <- 0:5
lam <- sum(g * y) / sum(g)                   #> 1.26
Eg <- c(sum(g) * dpois(0:4, lam), sum(g) * ppois(4, lam, lower.tail = FALSE))
sum((g - Eg)^2 / Eg)                         #> 1.551074

Practicals 5–7 — Continuous Fits and the Cauchy Test

CHOOSING THE FAMILY BEFORE FITTING IT

Three diagnostics, in order, settle which continuous family to try:

  1. Support. Strictly positive data rules out the normal, the Laplace and the Cauchy at once.
  2. The coefficient of variation. \(CV = s/\bar x\). For an exponential \(CV = 1\) exactly; \(CV < 1\) points to a gamma or Weibull with shape \(> 1\), \(CV > 1\) to a shape \(< 1\) or to a heavier tail.
  3. A probability plot. Whichever family straightens the plot is the one to fit — and the correlation of that plot is a usable measure of how well it did, as Practical 9 shows.

The Cauchy is a special case (Practical 6). It has no mean and no variance, so no moment-based method can be used at all, and a chi-square test is awkward because the tails are so heavy that cells must be pooled aggressively. Fit by quantiles instead: \(\hat\theta\) = the sample median, and \(\hat\lambda\) = half the interquartile range, since for the Cauchy the quartiles are at \(\theta \pm \lambda\). Then test with Kolmogorov–Smirnov, which uses the whole distribution function and needs no cells — and which is legitimate here by the Glivenko–Cantelli lemma of Probability Theory, Unit 3.

Two-parameter gamma (Practical 7). Method of moments gives starting values from \(\bar x = k/\theta\) and \(s^{2} = k/\theta^{2}\), namely \(\hat k = \bar x^{2}/s^{2}\) and \(\hat\theta = \bar x / s^{2}\); these are then refined by the method of scoring, since the maximum likelihood equations for the gamma have no closed form.

Practicals 8–10 — One Dataset, Three Families

THE DATA

Ten times to failure, in hours, in increasing order:

\[ 31,\ 58,\ 87,\ 119,\ 153,\ 192,\ 238,\ 296,\ 378,\ 520. \]

All three of the remaining practicals are worked on this one set, so the fits can be compared directly rather than each being judged in isolation.

PRACTICAL 9 — FITTING A WEIBULL BY THE WEIBULL PLOT

Step 1 — linearise. From \(F(t) = 1 - e^{-(t/\lambda)^{k}}\),

\[ 1 - F(t) = e^{-(t/\lambda)^{k}} \;\Rightarrow\; -\ln\left[1 - F(t)\right] = \left(\frac{t}{\lambda}\right)^{k} \;\Rightarrow\; \ln\left\{-\ln\left[1 - F(t)\right]\right\} = k \ln t - k \ln \lambda. \]

So plotting \(y = \ln\{-\ln[1-F]\}\) against \(x = \ln t\) gives a straight line of slope \(k\) and intercept \(-k\ln\lambda\).

Step 2 — estimate \(F\) at each point by the median rank \((i - 0.3)/(n + 0.4)\), which is the standard small-sample plotting position:

\(i\)\(t_{(i)}\)\(F = \frac{i-0.3}{10.4}\)\(x = \ln t\)\(y = \ln\{-\ln(1-F)\}\)
1310.0673083.433987−2.663843
2580.1634624.060443−1.723263
3870.2596154.465908−1.202023
41190.3557694.779123−0.821667
51530.4519235.030438−0.508595
61920.5480775.257495−0.230365
72380.6442315.4722710.032925
82960.7403855.6903590.299033
93780.8365385.9348940.593977
105200.9326926.2538290.992689

Step 3 — the regression sums.

\[ \sum x = 50.378748, \quad \sum y = -5.231133, \quad \sum x^{2} = 260.669666, \quad \sum xy = -17.594310, \quad n = 10. \]

Step 4 — the slope.

\[ \hat k = b = \frac{n\sum xy - \sum x \sum y}{n \sum x^{2} - \left(\sum x\right)^{2}} = \frac{10(-17.594310) - (50.378748)(-5.231133)}{10(260.669666) - (50.378748)^{2}}. \]

Numerator: \(-175.943100 + 263.537931 = 87.594831\). Denominator: \(2606.696660 - 2538.018250 = 68.678410\). So

\[ \hat k = \frac{87.594831}{68.678410} = 1.275435. \]

Step 5 — the intercept, and \(\lambda\).

\[ a = \bar y - b\bar x = -0.523113 - 1.275435 \times 5.037875 = -6.948594, \] \[ \hat\lambda = \exp\left(-\frac{a}{\hat k}\right) = \exp\left(\frac{6.948594}{1.275435}\right) = e^{5.448020} = 232.2977. \]

Step 6 — how good is the fit? The correlation of the plotted points is \(r = 0.999215\). A Weibull plot that straight is as strong an endorsement of the family as this sample size can give.

Step 7 — use the fitted model.

\[ \text{mean life} = \hat\lambda\,\Gamma\!\left(1 + \frac{1}{\hat k}\right) = 232.2977 \times \Gamma(1.784046) = 232.2977 \times 0.927246 = 215.3971 \text{ hours}, \] \[ R(200) = \exp\left\{-\left(\frac{200}{232.2977}\right)^{1.275435}\right\} = e^{-0.826186} = 0.437716. \]

Interpretation. \(\hat k = 1.275 > 1\), so the hazard rate rises with age — these components wear out, and an exponential model would be wrong. But \(1.275\) is only moderately above 1, so the wear-out is mild; with ten observations the standard error on \(\hat k\) is large enough that \(k = 1\) could not be firmly ruled out.

PRACTICAL 8 — FITTING A LOGNORMAL TO THE SAME DATA

Step 1 — maximum likelihood is just the normal fit on the log scale. Since \(\ln X \sim N(\mu, \sigma^{2})\),

\[ \hat\mu = \frac{1}{n}\sum_{i} \ln t_i, \qquad \hat\sigma^{2} = \frac{1}{n}\sum_{i}\left(\ln t_i - \hat\mu\right)^{2}. \]

(The divisor is \(n\), not \(n-1\): maximum likelihood, not the unbiased estimator.)

Step 2 — compute. The \(\ln t_i\) are the \(x\) column of the table above, whose sum is \(50.378748\), so

\[ \hat\mu = \frac{50.378748}{10} = 5.037875, \qquad \hat\sigma^{2} = 0.686784, \qquad \hat\sigma = 0.828724. \]

Step 3 — the fitted centres.

\[ \text{median} = e^{5.037875} = 154.14, \qquad \text{mean} = e^{5.037875 + 0.343392} = e^{5.381267} = 217.30. \]

Step 4 — a comparable prediction.

\[ P(X > 200) = 1 - \Phi\!\left(\frac{\ln 200 - 5.037875}{0.828724}\right) = 1 - \Phi(0.314269) = 0.376658. \]

Interpretation. The lognormal fitted mean, \(217.30\), is within \(1\%\) of the Weibull's \(215.3971\) — the two families agree closely in the middle. They part company in the tail: the lognormal gives \(P(X > 200) = 0.3767\) against the Weibull's \(0.4377\), a relative difference of \(14\%\). Choosing between them on fit statistics alone is unreliable with ten observations, so the choice should rest on what is known about the failure mechanism.

PRACTICAL 10 — FITTING A PARETO, AND READING THE WARNING

Step 1 — the maximum likelihood estimators. For a Pareto with both parameters unknown,

\[ \hat x_m = \min_i t_i = 31, \qquad \hat\alpha = \frac{n}{\sum_{i}\ln\left(t_i / \hat x_m\right)}. \]

Step 2 — compute. \(\sum_i \ln(t_i/31) = 16.038876\), so

\[ \hat\alpha = \frac{10}{16.038876} = 0.623485. \]

Step 3 — check what exists before reporting anything. By Unit 1, section 4, the Pareto mean requires \(\alpha > 1\) and the variance \(\alpha > 2\). Here \(\hat\alpha = 0.623 < 1\), so under the fitted model neither exists. Substituting into \(\alpha x_m/(\alpha - 1)\) returns \(-51.33\), a negative mean life, which is the arithmetic announcing that the formula has been used outside its range of validity.

Step 4 — what the fit does still support. Probabilities remain well defined even when moments do not:

\[ P(X > 200) = \left(\frac{31}{200}\right)^{0.623485} = 0.312740. \]

Interpretation. The Pareto is the wrong family for this dataset, and the fitted \(\hat\alpha\) says so plainly. The data have a definite scale — failures cluster between 30 and 520 hours — whereas the Pareto describes something with no characteristic scale at all. A negative fitted mean is not a numerical accident to be rounded away; it is the model reporting its own inapplicability, and the right response is to keep the Weibull. This is the single most useful habit in distribution fitting: check that the fitted parameters lie in the region where the quantities you intend to report actually exist.

ALL THREE FITS IN R 
t <- c(31, 58, 87, 119, 153, 192, 238, 296, 378, 520); n <- length(t)

## Weibull plot
i <- 1:n; Fi <- (i - 0.3) / (n + 0.4)
x <- log(t); y <- log(-log(1 - Fi))
fit <- lm(y ~ x); coef(fit)
k <- coef(fit)[2]; lambda <- exp(-coef(fit)[1] / k)
c(k = k, lambda = lambda)            #> k 1.275435   lambda 232.2977
cor(x, y)                            #> 0.999215
plot(x, y, pch = 19, xlab = "ln t", ylab = "ln(-ln(1-F))"); abline(fit, col = "red")

## Lognormal, by maximum likelihood
mu <- mean(log(t)); s2 <- mean((log(t) - mu)^2)
c(mu = mu, sigma = sqrt(s2))         #> mu 5.037875   sigma 0.828724

## Pareto, by maximum likelihood
xm <- min(t); alpha <- n / sum(log(t / xm))
alpha                                #> 0.623485
if (alpha <= 1) message("alpha <= 1: the fitted Pareto has no mean")

What the Practical Record Should Contain

FOR EACH EXPERIMENT
  1. The aim, in one line.
  2. The data, as given.
  3. The method, named — inverse transform, method of moments, maximum likelihood, probability plot — and why it was chosen over the alternatives.
  4. The manual computation, with every intermediate total shown, not only the final estimate.
  5. The R code and its output, with the two compared and any difference explained.
  6. The fitted curve drawn over a histogram or an empirical distribution function.
  7. The conclusion, stating the nature of the fitted curve — skewness, tail weight, whether the hazard rises or falls, and which moments exist.
