    1. Random Variable

    DEFINITION

    A random variable (r.v.) \(X\) is a real-valued function defined on the sample space \(S\) of a random experiment, i.e. \(X : S \to \mathbb{R}\). Each outcome \(\omega \in S\) is assigned a real number \(X(\omega)\).

    EXAMPLE 1

    Toss a coin twice; \(S = \{HH, HT, TH, TT\}\). Define \(X\) = number of heads.
    Then \(X(HH)=2,\;X(HT)=X(TH)=1,\;X(TT)=0\). \(X\) takes values 0, 1, 2.

    EXAMPLE 2

    Time (in minutes) a customer waits in a queue is a random variable \(T\). It can be any non-negative real number.

    ANOTHER DEFINITION — AND THE PROBABILITY SPACE

    A random variable is a function \(X(w)\) with domain \(S\) and range \((-\infty,\infty)\) such that for every real number \(a\), the event \(\{w : X(w)\le a\}\in B\), where \(B\) is the \(\sigma\)-field of events on \(S\).

    That condition is what makes \(P(X\le a)\) meaningful at all: it says every set the distribution function will ever be asked about is a set the probability function can measure.

    Note. The triplet \((S,B,P)\) is called the probability space, where

    • \(S\) : sample space of the random experiment;
    • \(B\) : a \(\sigma\)-field of subsets of \(S\) — the events, the sets that are given probabilities. For a finite \(S\) it can be all subsets; on the real line it is the Borel \(\sigma\)-field, the one generated by the intervals, which is where the name comes from. It is not, in general, every subset;
    • \(P\) : probability function on \(B\).
    EXAMPLE 3 (rolling a die)

    An experiment consists of rolling a die, so \(S=\{1,2,3,4,5,6\}\). Let the random variable \(X\) be the number of points turned on the face of the die. Then \(X(1)=1,\ X(2)=2,\ X(3)=3,\ X(4)=4,\ X(5)=5,\ X(6)=6\), and \(X\) takes the values \(1,2,3,4,5,6\).

    EXAMPLE 4 (a continuous one)

    The heights of a group of persons is a random variable taking values between 4 feet and 6 feet (say).

    Types of Random Variables

    There are two types of random variable: discrete and continuous.

    • Discrete r.v. — takes a finite or countable set of values (e.g., number of defectives, number of heads).
    • Continuous r.v. — takes any value in an interval of \(\mathbb{R}\) (e.g., height, weight, time).

    2. Probability Mass Function (PMF)

    DISCRETE RANDOM VARIABLE

    If a random variable takes at most a countable number of values it is called a discrete random variable. "At most countable" is the whole of it: finitely many values, or countably infinitely many, are both allowed.

    Examples. The number of heads in tossing three coins; the number of points turned on the face of a die; the number of births in a city; the number of telephone calls received in a particular day in a government office; the number of accidents occurring at a junction of a city.

    DEFINITION

    If \(X\) is a discrete r.v. taking values \(x_1, x_2, \ldots\), the function

    \[ p(x_i) \;=\; P(X = x_i) \]

    is called its probability mass function. It must satisfy:

    \[ (i)\quad p(x_i) \ge 0 \quad \text{for all } i, \qquad (ii)\quad \sum_{i} p(x_i) = 1 \]

    Probability distribution of a discrete random variable. The set of pairs \(\big(x_i,\,P(x_i)\big)\) is called the probability distribution of the discrete random variable — the values paired with their probabilities, nothing more.

    EXAMPLE 1

    For a fair die, \(X\) = number on top face has PMF \(p(x) = 1/6\) for \(x = 1,2,\ldots,6\). Sum = 1 ✓.

    EXAMPLE 2 (Find a constant)

    Let \(p(x) = kx\) for \(x = 1,2,3,4\). Then \(\sum p(x) = k(1+2+3+4) = 10k = 1\) ⇒ \(k = 1/10\).

    Hence \(p(1)=0.1,p(2)=0.2,p(3)=0.3,p(4)=0.4\).

    3. Probability Density Function (PDF)

    CONTINUOUS RANDOM VARIABLE

    If a random variable takes all the possible values between certain limits, it is called a continuous random variable.

    Examples. The age of a group of persons; the weights of competitors in a game; the heights of soldiers in the country; the temperature recorded in a city; the rainfall observed in a day in a hill area.

    DEFINITION

    The probability density function of a continuous random variable is denoted by \(f_X(x)\) or \(f(x)\). The function \(f(x)\) is called a probability density function if it satisfies:

    \[ (i)\;\; f(x) \ge 0 \;\;\forall x; \qquad (ii)\;\; \int_{-\infty}^{\infty} f(x)\,dx = 1; \qquad (iii)\;\; P(a \le X \le b) = \int_{a}^{b} f(x)\,dx \]

    Note: \(P(X = c) = 0\) for any single point \(c\) when \(X\) is continuous.

    EXAMPLE 1 (Find constant)

    \(f(x) = kx,\; 0 \le x \le 2\). Find \(k\).
    \(\int_0^2 kx\,dx = k \cdot 2 = 1 \Rightarrow k = 1/2\).

    EXAMPLE 2 (Compute probability)

    For \(f(x) = 3x^2\) on \([0,1]\): check \(\int_0^1 3x^2 dx = 1\) ✓.
    \(P(X \le 0.5) = \int_0^{0.5} 3x^2 dx = x^3|_0^{0.5} = 0.125\).

    4. Distribution Function (CDF)

    DEFINITION

    The distribution function of a random variable \(X\) is denoted by \(F_X(x)\) or \(F(x)\) and is defined as

    \[ F_X(x) \;=\; P(X \le x), \quad -\infty < x < \infty. \]

    For a discrete random variable,

    \[ F_X(x) = P(X\le x) = \sum_{x_i \le x} P(X = x_i), \]

    and for a continuous random variable,

    \[ F_X(x) = P(X\le x) = \int_{-\infty}^{x} f(t)\,dt . \]

    The summation index \(x_i\) and the integration variable \(t\) are dummies; \(x\) is the fixed upper limit, so it cannot also be the variable being summed or integrated.

    Properties of CDF

    1. \(0 \le F(x) \le 1\).
    2. \(F(-\infty) = 0,\; F(+\infty) = 1\).
    3. \(F\) is monotonically non-decreasing: \(x_1 < x_2 \Rightarrow F(x_1) \le F(x_2)\).
    4. \(F\) is right-continuous: \(\lim_{x \to a^+} F(x) = F(a)\).
    5. \(P(a < X \le b) = F(b) - F(a)\).
    6. For continuous \(X\): \(F'(x) = f(x)\) wherever the derivative exists.
    7. For discrete \(X\): \(F\) is a step function; jumps at each \(x_i\) by \(p(x_i)\).

    The Seven Properties, Proved

    The list above is the working summary. Below is the same ground covered properly: each property stated and then proved, in the order they build on one another. Everything rests on one move — writing an event as a union of disjoint events and adding the probabilities.

    1. If \(F(x)\) is the distribution function of a random variable \(X\) and \(a < b\), then \(P(a < X \le b) = F(b) - F(a)\).

    Proof. Express the event \(X\le b\) as the union of the two disjoint events \(X\le a\) and \(a < X\le b\):

    \[ X\le b = (X\le a)\cup(a < X\le b). \]

    Applying probabilities to both sides,

    \[ P(X\le b) = P\big[(X\le a)\cup(a < X\le b)\big] = P(X\le a) + P(a < X\le b) \]

    since the events are disjoint. Therefore

    \[ P(a < X\le b) = P(X\le b) - P(X\le a) = F(b) - F(a). \]

    2. \(P(a < X < b) = F(b) - F(a) - P(X=b)\).

    Proof. \(P(a < X < b) = P(a < X\le b) - P(X=b) = F(b) - F(a) - P(X=b)\).

    3. \(P(a \le X \le b) = P(X=a) + F(b) - F(a)\).

    Proof. \(P(a \le X\le b) = P(X=a) + P(a < X\le b) = P(X=a) + F(b) - F(a)\).

    4. \(P(a \le X < b) = F(b) - F(a) - P(X=b) + P(X=a)\).

    Proof. \(P(a \le X < b) = P(X=a) - P(X=b) + P(a < X\le b) = P(X=a) - P(X=b) + F(b) - F(a)\).

    Properties 1 to 4 are one fact seen four ways: whether each endpoint is included costs you exactly \(P(X=a)\) or \(P(X=b)\). For a continuous random variable those are zero and all four collapse into one.

    5. If \(F(x)\) is the distribution function of a random variable \(X\), then \(0 \le F(x) \le 1\).

    Proof. By definition \(F(x) = P(X\le x)\). Since a probability lies between 0 and 1, the distribution function lies between 0 and 1:

    \[ 0 \le P(X\le x) \le 1 \;\Longrightarrow\; 0 \le F(x) \le 1 . \]

    6. If \(F(x)\) is the distribution function of \(X\), then \(F(x)\le F(y)\) for \(x < y\).

    Proof. For \(x < y\), property 1 gives \(P(x < X\le y) = F(y)-F(x)\). Since a probability is always \(\ge 0\),

    \[ P(x < X\le y)\ge 0 \;\Longrightarrow\; F(y)-F(x)\ge 0 \;\Longrightarrow\; F(y)\ge F(x), \]

    that is \(F(x)\le F(y)\) for \(x < y\). The distribution function never decreases.

    7. If \(F(x)\) is the distribution function of \(X\), then \(F(-\infty)=0\) and \(F(\infty)=1\).

    Proof. Express the whole sample space \(S\) as a countable union of disjoint events:

    \[ S = \left[\bigcup_{n=1}^{\infty}(-n < X \le -n+1)\right] \cup \left[\bigcup_{n=0}^{\infty}(n < X \le n+1)\right]. \]

    Taking probabilities on both sides, and using that the events are disjoint together with countable additivity,

    \[ 1 = P\left[\bigcup_{n=1}^{\infty}(-n < X\le -n+1)\right] + P\left[\bigcup_{n=0}^{\infty}(n < X\le n+1)\right] \] \[ = \sum_{n=1}^{\infty} P(-n < X\le -n+1) + \sum_{n=0}^{\infty} P(n < X\le n+1) \] \[ = \sum_{n=1}^{\infty}\big[F(-n+1)-F(-n)\big] + \sum_{n=0}^{\infty}\big[F(n+1)-F(n)\big] \]

    Both sums telescope:

    \[ = \big[F(0)-F(-1)+F(-1)-F(-2)+F(-2)-F(-3)+\cdots\big] + \big[F(1)-F(0)+F(2)-F(1)+\cdots\big] \] \[ = F(\infty)-F(-\infty) \qquad\Longrightarrow\qquad F(\infty)-F(-\infty) = 1 . \tag{1} \]

    From property 6, since \(-\infty < \infty\),

    \[ F(-\infty) \le F(\infty). \tag{2} \]

    From property 5,

    \[ 0 \le F(-\infty) \le 1, \qquad 0 \le F(\infty) \le 1, \tag{3} \]

    so in particular

    \[ F(-\infty)\ge 0 \quad\text{and}\quad F(\infty)\le 1 . \tag{4} \]

    From (2) and (3),

    \[ 0 \le F(-\infty) \le F(\infty) \le 1 . \tag{5} \]

    From (1), (4) and (5) together, the only possibility is

    \[ F(-\infty) = 0, \qquad F(\infty) = 1 . \quad\blacksquare \]

    Worth noticing what did the work: (1) says the two values differ by exactly 1, and (5) says both sit inside \([0,1]\). Only the endpoints satisfy both.

    EXAMPLE 1 (Discrete)

    Toss two fair coins; \(X\) = number of heads. PMF: \(p(0)=1/4, p(1)=1/2, p(2)=1/4\).

    CDF: \(F(0) = 1/4,\; F(1) = 3/4,\; F(2) = 1\). \(F\) is a step function.

    EXAMPLE 2 (Continuous)

    For \(f(x) = 3x^2\) on [0,1]: \(F(x) = \int_0^x 3t^2 dt = x^3\) for \(0 \le x \le 1\).
    \(F(x) = 0\) for \(x < 0\) and \(F(x) = 1\) for \(x > 1\).

    Check: \(P(0.2 < X \le 0.5) = F(0.5) - F(0.2) = 0.125 - 0.008 = 0.117\).

    5. Functions of a Random Variable

    If \(Y = g(X)\) is a function of an r.v. \(X\), then \(Y\) is also an r.v.

    Discrete case

    If \(X\) takes values \(x_i\) with PMF \(p(x_i)\) and \(Y = g(X)\), then \(P(Y=y) = \sum_{x_i:\,g(x_i)=y} p(x_i)\).

    Continuous case

    If \(g\) is a one-to-one differentiable function and \(Y = g(X)\):

    \[ f_Y(y) \;=\; f_X(x)\, \left|\dfrac{dx}{dy}\right| \;=\; f_X(g^{-1}(y))\,\left|\dfrac{d}{dy}g^{-1}(y)\right| \]
    DERIVATION — via the CDF

    Work through the distribution function. If \(g\) is increasing, \(Y \le y \iff X \le g^{-1}(y)\), so

    \[ F_Y(y) = P\big(g(X)\le y\big) = P\big(X \le g^{-1}(y)\big) = F_X\!\big(g^{-1}(y)\big). \]

    Differentiating with the chain rule gives \(f_Y(y) = f_X(g^{-1}(y))\,\dfrac{d}{dy}g^{-1}(y)\). If \(g\) is decreasing the inequality flips and the derivative is negative, so the two cases combine into the single \(|\,dx/dy\,|\) formula — the absolute value simply keeps the density positive. (Example 2 below is exactly this with \(g(x) = -\ln x\).)

    EXAMPLE 1 (Discrete)

    \(X\) takes values \(-1,0,1,2\) each with probability \(1/4\). Let \(Y = X^2\). Then \(Y\) takes 0,1,4 with probabilities \(P(Y=0) = 1/4,\; P(Y=1) = 1/4 + 1/4 = 1/2,\; P(Y=4) = 1/4\).

    EXAMPLE 2 (Continuous)

    \(X \sim\) Uniform(0,1) so \(f_X(x) = 1\) on (0,1). Let \(Y = -\ln X\), so \(X = e^{-Y}\), \(dX/dY = -e^{-y}\).

    \(f_Y(y) = 1 \cdot e^{-y} = e^{-y}\) for \(y > 0\). Hence \(Y \sim\) Exponential(1).

    6. Moments from PMF / PDF

    6.1 \(r^{th}\) Raw Moment about origin

    \[ \mu'_r \;=\; E(X^r) \;=\; \begin{cases} \displaystyle\sum_x x^r\, p(x), & \text{discrete}\\[4pt] \displaystyle\int_{-\infty}^{\infty} x^r\, f(x)\,dx, & \text{continuous} \end{cases} \]

    6.2 \(r^{th}\) Central Moment

    \[ \mu_r \;=\; E[(X - \mu)^r], \quad \mu = E(X) = \mu'_1 \]

    6.3 Special Values

    • Mean = \(\mu = \mu'_1\)
    • \(\mu_1 = 0\)
    • Variance = \(\mu_2 = \mu'_2 - (\mu'_1)^2\)
    • \(\mu_3 = \mu'_3 - 3\mu'_2\mu'_1 + 2(\mu'_1)^3\)
    • \(\mu_4 = \mu'_4 - 4\mu'_3\mu'_1 + 6\mu'_2(\mu'_1)^2 - 3(\mu'_1)^4\)
    EXAMPLE 1 (Discrete)

    For \(p(x) = x/10\), \(x = 1,2,3,4\):

    \(\mu'_1 = \sum x p(x) = 1(0.1)+2(0.2)+3(0.3)+4(0.4) = 3.0\).

    \(\mu'_2 = \sum x^2 p(x) = 1(0.1)+4(0.2)+9(0.3)+16(0.4) = 10.0\).

    \(\sigma^2 = 10 - 9 = 1\); SD = 1.

    EXAMPLE 2 (Continuous)

    \(f(x) = 3x^2\) on [0,1]:

    \(\mu'_1 = \int_0^1 x \cdot 3x^2 dx = 3/4\).

    \(\mu'_2 = \int_0^1 x^2 \cdot 3x^2 dx = 3/5\).

    \(\sigma^2 = 3/5 - (3/4)^2 = 0.6 - 0.5625 = 0.0375\). SD = 0.1936.

    6.4 The Working Formula Lists

    VARIOUS FORMULAE ON A DISCRETE RANDOM VARIABLE \[ \text{Mean} = \sum x\,P(x), \qquad \text{Variance} = \sum x^{2}P(x) - (\text{mean})^{2}, \qquad F(x) = P(X\le x) = \sum^{x} P(X=x) \]

    Moments about origin (non-central moments)

    \[ \mu_1' = \sum x\,P(x), \quad \mu_2' = \sum x^{2}P(x), \quad \mu_3' = \sum x^{3}P(x), \quad \mu_4' = \sum x^{4}P(x) \]
    VARIOUS FORMULAE ON A CONTINUOUS RANDOM VARIABLE \[ \text{Mean} = \int x\,f(x)\,dx, \qquad \text{Variance} = \int x^{2}f(x)\,dx - (\text{mean})^{2} \]

    The harmonic mean \(H\) is given by

    \[ \frac1H = \int \frac1x\,f(x)\,dx . \]

    The geometric mean \(G\) is given by

    \[ \log G = \int \log x\; f(x)\,dx . \]

    The median \(M\) is given by (in the range \(a,b\))

    \[ \int_{a}^{M} f(x)\,dx = \int_{M}^{b} f(x)\,dx = \frac12, \qquad\text{i.e.}\qquad \int_{a}^{M} f(x)\,dx = \frac12 \quad\text{or}\quad \int_{M}^{b} f(x)\,dx = \frac12 . \]

    Mean deviation about the mean

    \[ \text{M.D.} = \int |x - \text{mean}|\,f(x)\,dx . \]

    The \(r\)th moment about origin

    \[ \mu_r' = \int x^{r} f(x)\,dx . \]

    The absolute value in the mean deviation is why that one integral always splits in two, at the mean: below it the bracket is negative and the sign flips. Problem 3 below does exactly that.

    7. Skewness & Kurtosis from PMF / PDF

    SKEWNESS (β₁ & γ₁) \[ \beta_1 \;=\; \dfrac{\mu_3^2}{\mu_2^3}, \qquad \gamma_1 \;=\; \dfrac{\mu_3}{\mu_2^{3/2}} \]
    • Symmetric ⇒ \(\mu_3 = 0\), so \(\gamma_1 = 0\). The converse fails: some asymmetric distributions also have \(\mu_3 = 0\), so \(\gamma_1 = 0\) alone does not prove symmetry.
    • \(\gamma_1 > 0\) ⇒ right-skewed; \(\gamma_1 < 0\) ⇒ left-skewed.
    KURTOSIS (β₂ & γ₂) \[ \beta_2 \;=\; \dfrac{\mu_4}{\mu_2^2}, \qquad \gamma_2 \;=\; \beta_2 - 3 \]
    • \(\beta_2 = 3\) ⇒ Mesokurtic (normal-like).
    • \(\beta_2 > 3\) ⇒ Leptokurtic.
    • \(\beta_2 < 3\) ⇒ Platykurtic.
    EXAMPLE 1 (Discrete)

    Symmetric PMF: \(p(-1) = p(0) = p(1) = 1/3\).
    \(\mu = 0,\; \mu_2 = (1+0+1)/3 = 2/3,\; \mu_3 = 0,\; \mu_4 = (1+0+1)/3 = 2/3\).
    \(\beta_1 = 0\) (symmetric); \(\beta_2 = (2/3)/(2/3)^2 = 1.5\) → platykurtic.

    EXAMPLE 2 (Continuous)

    For \(f(x) = e^{-x},\; x \ge 0\) (Exponential(1)).

    \(\mu'_r = \int_0^\infty x^r e^{-x} dx = r!\). So \(\mu'_1 = 1,\; \mu'_2 = 2,\; \mu'_3 = 6,\; \mu'_4 = 24\).

    \(\mu_2 = 2 - 1 = 1;\; \mu_3 = 6 - 3(2)(1) + 2(1)^3 = 2;\; \mu_4 = 24 - 4(6)(1) + 6(2)(1) - 3 = 9\).

    \(\beta_1 = 4,\; \gamma_1 = 2\) (strongly right-skewed).

    \(\beta_2 = 9,\; \gamma_2 = 6\) (strongly leptokurtic, heavy tails).

    Worked Problems on Continuous Random Variables

    Fifteen problems. Between them they use every formula in §6.4 at least once, which is the point of reading them as a run rather than picking one.

    PROBLEM 1 — find the constant, then the mean

    For the density function \(f(x)=Cx(1-x)^{2},\ 0<x<1\), find (i) the constant \(C\), (ii) the mean.

    (i) By the definition of a p.d.f., \(\int f(x)\,dx = 1\):

    \[ C\int_{0}^{1}(x-2x^{2}+x^{3})\,dx = 1 \quad\Longrightarrow\quad C\left[\frac{x^{2}}{2}-\frac{2x^{3}}{3}+\frac{x^{4}}{4}\right]_{0}^{1} = 1 \] \[ C\left(\frac12-\frac23+\frac14\right) = C\left(\frac{1}{12}\right) = 1 \quad\therefore\quad C = 12 . \]

    (ii)

    \[ \text{Mean} = 12\int_{0}^{1}(x^{2}-2x^{3}+x^{4})\,dx = 12\left(\frac13-\frac12+\frac15\right) = 12\cdot\frac{1}{30} = \frac{2}{5} . \]
    PROBLEM 2 — two unknowns from two conditions

    A continuous random variable \(X\) has the p.d.f. \(f(x)=A+Bx,\ 0\le x\le 1\). If the mean of the distribution is \(\tfrac{7}{12}\), find \(A\) and \(B\).

    Condition 1 — it is a density.

    \[ \int_{0}^{1}(A+Bx)\,dx = 1 \quad\Longrightarrow\quad A+\frac{B}{2}=1 \quad\Longrightarrow\quad 2A+B = 2 . \tag{1} \]

    Condition 2 — the mean is \(\tfrac{7}{12}\).

    \[ \int_{0}^{1} x(A+Bx)\,dx = \frac{7}{12} \quad\Longrightarrow\quad \frac{A}{2}+\frac{B}{3}=\frac{7}{12} \quad\Longrightarrow\quad 6A+4B = 7 . \tag{2} \]

    Solving, \(4\times(1)\) gives \(8A+4B=8\); subtracting (2) gives \(2A=1\), \(A=\frac{1}{2}\), and then \(1+B=2\), so \(B=1\).

    So the density is \(f(x)=\tfrac12+x\) on \([0,1]\). Check: it is never negative, and the mean, a little above \(\tfrac12\), reflects a density that rises to the right.

    PROBLEM 3 — verify a density, find its median and mean deviation

    The proportion of a day's output that is rejected, \(X\), has p.d.f. \(f(x)=12x^{2}(1-x),\ 0\le x\le 1\). (i) Check that it is a p.d.f. (ii) Determine \(b\) such that \(P(X<b)=P(X>b)\). (iii) Find the mean deviation about the mean.

    (i)

    \[ \int_{0}^{1}12x^{2}(1-x)\,dx = 12\left[\frac{x^{3}}{3}-\frac{x^{4}}{4}\right]_{0}^{1} = 12\cdot\frac{1}{12} = 1 . \]

    So the given \(f(x)\) is a p.d.f.

    (ii) \(P(X<b)=P(X>b)\) means \(b\) is the median, so each side is \(\tfrac12\):

    \[ \int_{0}^{b}12x^{2}(1-x)\,dx = \frac12 \quad\Longrightarrow\quad 4b^{3}-3b^{4} = \frac12 \quad\Longrightarrow\quad 6b^{4}-8b^{3}+1 = 0 . \]

    This quartic has two real roots, \(b \approx 0.6143\) and \(b \approx 1.2475\) (found by Newton's method or a calculator); only the first lies in \([0,1]\), so \(b = 0.6143\). It sits above \(\tfrac12\) because the density leans right.

    (iii) First the mean:

    \[ \text{mean} = \int_{0}^{1}x\cdot12x^{2}(1-x)\,dx = 12\left[\frac14-\frac15\right] = \frac{12}{20} = \frac{3}{5} . \]

    Then, splitting at the mean because of the absolute value,

    \[ \text{M.D.} = \int_{0}^{3/5}\left(\tfrac35-x\right)12x^{2}(1-x)\,dx + \int_{3/5}^{1}\left(x-\tfrac35\right)12x^{2}(1-x)\,dx = \frac{2592}{15625} \approx 0.1659 . \]

    (The two pieces are \(\frac{1296}{15625}\) and \(\frac{1296}{15625}\); they are equal, as they must be, because \(\int (x-\mu)f\,dx = 0\) forces the deviations below and above the mean to balance.)

    PROBLEM 4 — a median and a percentile

    A continuous random variable \(X\) has the p.d.f. \(f(x)=4x^{3},\ 0\le x\le 1\). Find \(a\) and \(b\) such that (i) \(P(X\le a)=P(X>a)\), (ii) \(P(X>b)=0.1\).

    (i) By the property of the median, \(P(X\le a)=\tfrac12\):

    \[ \int_{0}^{a}4x^{3}\,dx = a^{4} = \frac12 \quad\Longrightarrow\quad a = \sqrt[4]{\tfrac12} = 0.8409 . \]

    (ii)

    \[ \int_{b}^{1}4x^{3}\,dx = 1-b^{4} = 0.1 \quad\Longrightarrow\quad b^{4} = 0.9 \quad\Longrightarrow\quad b = \sqrt[4]{0.9} = 0.9740 . \]

    So \(b\) is the 90th percentile.

    PROBLEM 5 — a three-piece density

    A continuous random variable \(X\) has the p.d.f.

    \[ f(x) = \begin{cases} k(4+x)^{2}, & -4\le x\le -2\\[2pt] k(8-x^{2}), & -2\le x\le 2\\[2pt] k(4-x)^{2}, & 2\le x\le 4 \end{cases} \]

    (i) Find \(k\) and check that the pieces join without a jump. (ii) Find the mean and variance.

    (i) Integrating piece by piece,

    \[ k\left\{\int_{-4}^{-2}(4+x)^{2}dx + \int_{-2}^{2}(8-x^{2})dx + \int_{2}^{4}(4-x)^{2}dx\right\} = k\left\{\frac{8}{3} + \frac{80}{3} + \frac{8}{3}\right\} = 32k = 1 , \]

    so \(k = \frac{1}{32}\). At \(x=-2\) the outer piece gives \(k(2)^2 = 4k\) and the middle piece \(k(8-4) = 4k\); the same holds at \(x=2\), so the density is continuous.

    (ii) The density is symmetric about 0 (each piece is matched by its mirror image), and the arithmetic bears that out: the three pieces of \(\int x f\,dx\) are \(- \frac{5}{24}\), 0 and \(\frac{5}{24}\), so the mean is \(0\).

    With the mean at 0 the variance is just \(\int x^{2}f(x)\,dx\):

    \[ \text{Variance} = \frac{1}{32}\left\{\frac{256}{15} + \frac{448}{15} + \frac{256}{15}\right\} = 2 . \]
    PROBLEM 6 — a trapezoidal density

    Let \(X\) be a continuous random variable with p.d.f.

    \[ f(x) = \begin{cases} ax, & 0\le x\le 2\\[2pt] 2a, & 2\le x\le 3\\[2pt] a(5-x), & 3\le x\le 5 \end{cases} \]

    (i) Determine \(a\). (ii) Compute \(P(1\le X\le 4)\).

    (i) By the definition of a p.d.f.,

    \[ \int_{0}^{2}ax\,dx + \int_{2}^{3}2a\,dx + \int_{3}^{5}a(5-x)\,dx = 2a + 2a + 2a = 6a = 1 \quad\therefore\quad a = \frac{1}{6} . \]

    (The three pieces are two triangles of area \(2a\) and a rectangle of area \(2a\); the picture gives the same sum.)

    (ii) The interval cuts into both sloping pieces, so the integral splits at 2 and 3:

    \[ P(1\le X\le 4) = \int_{1}^{2}\tfrac16 x\,dx + \int_{2}^{3}\tfrac13\,dx + \int_{3}^{4}\tfrac16(5-x)\,dx = \frac14 + \frac13 + \frac14 = \frac{5}{6} . \]
    PROBLEM 7 — probabilities from a uniform density

    If a random variable \(X\) has the density function \(f(x)=\tfrac16\) for \(-3<x<3\) and 0 otherwise, find (i) \(P(X<2)\), (ii) \(P(|X|>2)\), (iii) \(P(3X-1>2)\).

    \[ \text{(i)}\quad P(X<2) = \int_{-3}^{2}\frac16\,dx = \frac56 \] \[ \text{(ii)}\quad P(|X|>2) = 1-P(-2\le X\le 2) = 1-\int_{-2}^{2}\frac16\,dx = 1-\frac46 = \frac13 \] \[ \text{(iii)}\quad P(3X-1>2) = P(3X>3) = P(X>1) = \int_{1}^{3}\frac16\,dx = \frac13 \]

    Part (iii) is the useful habit: rearrange the inequality into a statement about \(X\) first, then integrate. Nothing about the density changes.

    PROBLEM 8 — four averages, and a symmetry check

    A continuous random variable \(X\) has the p.d.f. \(f(x)=y_0\,x^{2}(1-x)^{2},\ 0\le x\le 1\), where \(y_0\) is a constant. Find (i) the arithmetic mean, (ii) the harmonic mean, (iii) the median, (iv) the mode, and (v) show that the distribution is symmetrical.

    Finding \(y_0\).

    \[ y_0\int_{0}^{1}(x^{2}-2x^{3}+x^{4})\,dx = y_0\left(\frac13-\frac12+\frac15\right) = \frac{y_0}{30} = 1 \quad\Longrightarrow\quad y_0 = 30, \]

    so \(f(x)=30x^{2}(1-x)^{2},\ 0\le x\le 1\).

    (v) first: symmetry. Symmetry about \(\tfrac12\) means \(f(1-x) = f(x)\). Here \(f(1-x) = 30(1-x)^{2}x^{2} = f(x)\), so the distribution is symmetrical about \(\tfrac12\).

    (i) Arithmetic mean. \(\text{Mean} = 30\int_{0}^{1}(x^{3}-2x^{4}+x^{5})\,dx = 30\left(\frac14-\frac25+\frac16\right) = 30\cdot\frac{1}{60} = \frac{1}{2}\), as symmetry requires.

    (ii) Harmonic mean. \(\dfrac1H = \int_{0}^{1}\frac1x\cdot30x^{2}(1-x)^{2}\,dx = 30\left(\frac12-\frac23+\frac14\right) = \frac{5}{2}\), so \(H = \frac{2}{5}\). It is below the arithmetic mean, as a harmonic mean always is.

    (iii) Median. By symmetry \(P(X\le\tfrac12) = P(X\ge\tfrac12) = \tfrac12\), so the median is \(\tfrac12\); integrating \(\int_0^{1/2} 30x^2(1-x)^2dx = 30\left(\frac{1}{24}-\frac{1}{32}+\frac{1}{160}\right) = \frac{1}{2}\) confirms it.

    (iv) Mode. \(f'(x) = 60x(1-x)(1-2x) = 0\) at \(x = 0, \tfrac12, 1\); the end points give \(f=0\), a minimum, and at \(x=\tfrac12\), \(f''(\tfrac12) = -30 < 0\), so the mode is \(\tfrac12\).

    Mean = median = mode = \(\tfrac12\), as (v) predicts; but that equality on its own would not prove symmetry: an asymmetric distribution can have all three equal.

    PROBLEM 9 — an exponential density, four ways

    The p.d.f. of a random variable \(X\) is \(f(x)=2e^{-2x},\ x\ge 0\). Find (i) the mean and variance, (ii) the \(r\)th moment about the origin, (iii) the distribution function.

    (i) Mean, integrating by parts:

    \[ \text{Mean} = \int_{0}^{\infty}2xe^{-2x}\,dx = \left[-xe^{-2x}\right]_{0}^{\infty} + \int_{0}^{\infty}e^{-2x}\,dx = 0 + \frac12 = \frac{1}{2} . \]

    Variance. \(\int_0^\infty 2x^2e^{-2x}dx = \tfrac12\) (by parts twice, or by (ii) below), so Variance \(= \tfrac12 - \left(\tfrac12\right)^2 = \frac{1}{4}\).

    (ii) \(r\)th moment about origin. Put \(u = 2x\) and use the gamma integral:

    \[ \mu_r' = \int_{0}^{\infty}x^{r}\,2e^{-2x}\,dx = \frac{1}{2^{r}}\int_{0}^{\infty}u^{r}e^{-u}\,du = \frac{\Gamma(r+1)}{2^{r}} = \frac{r!}{2^{r}}, \]

    which gives the mean and variance again: \(\mu_1'=\tfrac12\), \(\mu_2'=\tfrac{2}{4}=\tfrac12\), variance \(=\tfrac12-\tfrac14=\tfrac14\).

    (iii) Distribution function.

    \[ F(x) = \int_{0}^{x}2e^{-2t}\,dt = \left[-e^{-2t}\right]_{0}^{x} = 1-e^{-2x}, \quad x \ge 0 . \]
    PROBLEM 10 — a gamma-shaped density

    For a continuous random variable \(X\), \(f(x)=Kx^{3}e^{-x},\ x\ge 0\). Find (i) \(K\), (ii) the mean, (iii) the variance, (iv) the standard deviation.

    (i) \(K\int_0^\infty x^3e^{-x}dx = K\,\Gamma(4) = 6K = 1\), so \(K = \frac{1}{6}\).

    (ii) \(\text{Mean} = \tfrac16\int_0^\infty x^4e^{-x}dx = \tfrac16\Gamma(5) = \tfrac{24}{6} = 4\).

    (iii) \(\text{Variance} = \tfrac16\Gamma(6) - 4^2 = \tfrac{120}{6} - 16 = 4\).

    (iv) S.D. \(=\sqrt{4} = 2\).

    The pattern \(x^{k-1}e^{-x}/\Gamma(k)\) has mean and variance both equal to \(k\); here \(k = 4\).

    PROBLEM 11 — when is \(Ke^{ax}\) a density at all?

    Find the conditions under which \(f(x)=Ke^{ax},\ x>1\) is a frequency function, and find \(K\).

    Solution. Since the total probability is unity,

    \[ \int_{1}^{\infty}Ke^{ax}\,dx = 1 \quad\Longrightarrow\quad K\left[\frac{e^{ax}}{a}\right]_{1}^{\infty} = 1 . \]

    The integral converges only for negative \(a\). Let \(a=-c\) with \(c>0\):

    \[ K\left[\frac{e^{-cx}}{-c}\right]_{1}^{\infty} = \frac{K e^{-c}}{c} = 1 \quad\Longrightarrow\quad K = c\,e^{c} = -a\,e^{-a} . \]

    The condition and the constant arrive together: the density exists only when \(a<0\), and then \(K=-ae^{-a}\), which is positive, as a density's constant must be. (Starting the range at 1 rather than 0 is what brings in the factor \(e^{-a}\).)

    PROBLEM 12 — skewness and kurtosis of \(2e^{-2x}\)

    The p.d.f. of \(X\) is \(f(x)=2e^{-2x},\ x\ge 0\). Find (i) the coefficient of skewness \(\beta_1\), (ii) the coefficient of kurtosis \(\beta_2\).

    Solution. From Problem 9, \(\mu_r' = r!/2^{r}\), so

    \[ \mu_1' = \frac{1}{2}, \quad \mu_2' = \frac{1}{2}, \quad \mu_3' = \frac{3}{4}, \quad \mu_4' = \frac{3}{2} . \]

    By the interrelations, the central moments:

    \[ \mu_2 = \tfrac12-\tfrac14 = \frac{1}{4}, \qquad \mu_3 = \tfrac34-3\cdot\tfrac12\cdot\tfrac12+2\cdot\tfrac18 = \frac{1}{4}, \] \[ \mu_4 = \tfrac32-4\cdot\tfrac34\cdot\tfrac12+6\cdot\tfrac12\cdot\tfrac14-3\cdot\tfrac{1}{16} = \frac{9}{16} . \] \[ \text{(i)}\quad \beta_1 = \frac{\mu_3^{2}}{\mu_2^{3}} = \frac{(1/4)^{2}}{(1/4)^{3}} = 4, \qquad \text{(ii)}\quad \beta_2 = \frac{\mu_4}{\mu_2^{2}} = \frac{9/16}{(1/4)^{2}} = 9 . \]

    Positively skewed and leptokurtic. These are the same \(\beta_1 = 4\) and \(\beta_2 = 9\) as for \(e^{-x}\): the rate 2 only rescales \(x\), and \(\beta_1\), \(\beta_2\) are ratios that do not change with scale.

    PROBLEM 13 — moments of a uniform density

    If a random variable \(X\) has the density function \(f(x)=\tfrac16\) for \(-3<x<3\) and 0 otherwise, find the first four moments about the mean.

    Solution. The \(r\)th moment about the origin is

    \[ \mu_r' = \int_{-3}^{3}x^{r}\cdot\frac16\,dx = \frac{3^{\,r+1}-(-3)^{\,r+1}}{6(r+1)} . \] \[ \mu_1' = 0, \qquad \mu_2' = \frac{27+27}{18} = 3, \qquad \mu_3' = 0, \qquad \mu_4' = \frac{243+243}{30} = \frac{81}{5} . \]

    The odd ones vanish, which is symmetry showing up in the arithmetic. With \(\mu_1' = 0\) the central moments equal the raw ones: \(\mu_1 = 0\), \(\mu_2 = 3\), \(\mu_3 = 0\), \(\mu_4 = \frac{81}{5}\).

    So \(\beta_2 = \mu_4/\mu_2^2 = \frac{9}{5}\), below 3: a uniform distribution is platykurtic, whatever its range.

    PROBLEM 14 — first four moments about the mean for \(4x^{3}\)

    A continuous random variable \(X\) has the p.d.f. \(f(x)=4x^{3},\ 0\le x\le 1\). Find the first four moments about the mean.

    \[ \mu_r' = \int_{0}^{1}x^{r}\cdot 4x^{3}\,dx = \frac{4}{r+4}, \qquad \mu_1' = \frac{4}{5}, \quad \mu_2' = \frac{2}{3}, \quad \mu_3' = \frac{4}{7}, \quad \mu_4' = \frac{1}{2} . \]

    Moments about the mean, using the relations:

    \[ \mu_1 = 0, \qquad \mu_2 = \frac23-\left(\frac45\right)^{2} = \frac{2}{75} = 0.02667, \] \[ \mu_3 = \frac47-3\cdot\frac23\cdot\frac45+2\left(\frac45\right)^{3} = - \frac{4}{875} = -0.004571, \] \[ \mu_4 = \frac12-4\cdot\frac47\cdot\frac45+6\cdot\frac23\left(\frac45\right)^{2}-3\left(\frac45\right)^{4} = \frac{23}{8750} = 0.002629 . \]

    A negative \(\mu_3\) says the distribution leans left, which matches a density that rises towards \(x=1\).

    Why the fractions. \(\mu_4\) is the small difference of four numbers between 0.5 and 2.3, so rounding any of them to two places first can change the answer completely. Keep fractions until the last line.

    PROBLEM 15 — skewness and kurtosis of \(\tfrac16 x^{3}e^{-x}\)

    For a continuous random variable \(X\), \(f(x)=\tfrac16 x^{3}e^{-x},\ x\ge 0\). Find (i) the coefficient of skewness, (ii) the coefficient of kurtosis.

    \[ \mu_r' = \frac16\int_{0}^{\infty}e^{-x}x^{\,(r+4)-1}\,dx = \frac{\Gamma(r+4)}{6} = \frac{(r+3)!}{6} . \] \[ \mu_1' = 4, \qquad \mu_2' = 20, \qquad \mu_3' = 120, \qquad \mu_4' = 840 . \] \[ \mu_2 = 20-4^{2} = 4, \qquad \mu_3 = 120-3(20)(4)+2(4)^{3} = 8, \] \[ \mu_4 = 840-4(120)(4)+6(20)(4)^{2}-3(4)^{4} = 72 . \] \[ \text{(i)}\quad \beta_1 = \frac{8^{2}}{4^{3}} = 1, \qquad \text{(ii)}\quad \beta_2 = \frac{72}{4^{2}} = \frac{9}{2} > 3 . \]

    Positively skewed and leptokurtic. Compare Problem 10's shape number \(k = 4\): for this family \(\beta_1 = 4/k\) and \(\beta_2 = 3 + 6/k\), so both move towards the normal values 0 and 3 as \(k\) grows.

    Key Take-aways from Unit 2

    • Random variable assigns numbers to outcomes; can be discrete or continuous.
    • PMF for discrete, PDF for continuous; both must integrate (or sum) to 1.
    • CDF \(F(x) = P(X \le x)\) is non-decreasing, right-continuous, with limits 0 and 1.
    • For continuous \(X\): \(F'(x) = f(x)\); for discrete \(X\): \(F\) jumps by \(p(x_i)\).
    • Moments: \(\mu'_r = E(X^r)\); skewness and kurtosis are unit-free shape descriptors.
    • The triplet \((S,B,P)\) is the probability space. Requiring \(\{w:X(w)\le a\}\in B\) is exactly what makes \(P(X\le a)\) — and therefore the distribution function — meaningful.
    • Properties 1 to 4 of the distribution function are one fact seen four ways: including or excluding an endpoint costs \(P(X=a)\) or \(P(X=b)\), which is zero for a continuous variable.
    • \(F(-\infty)=0\) and \(F(\infty)=1\) are not assumed. They follow from writing \(S\) as a countable union of disjoint intervals: the telescoping sum forces the two values to differ by 1 while both lie in \([0,1]\), and only the endpoints do both.
    • For a continuous variable the harmonic mean, geometric mean, median and mean deviation are all single integrals against \(f(x)\). The mean deviation is the one that splits, at the mean, because of the absolute value.
    • The gamma integral \(\int_0^\infty e^{-x}x^{\,r+1-1}dx=\Gamma(r+1)=r!\) turns every moment of \(e^{-x}\) into a factorial, which is why \(\beta_1=4\) and \(\beta_2=9\) drop out with no integration at all.
