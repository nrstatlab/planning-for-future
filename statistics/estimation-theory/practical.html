    Practical — Estimation Theory (STS-205, Section A)

    The five prescribed Section A practicals worked with full arithmetic: jackknife and bootstrap estimates, the MLE for a Cauchy location by Fisher scoring, exact confidence limits for a normal population, and large-sample limits for the binomial, Poisson and exponential.

    About this course. STS-205 is a conventional practical in two sections: Section A, Estimation Theory — the five experiments worked here — and Section B, Multivariate Analysis, which belongs to Multivariate Analysis (STS-202) and is written with that course. Both sections are examined by hand, so every experiment below is worked with full arithmetic; R is shown only as a check.

    Practical 1 — Jackknife Estimates

    WORKED IN FULL IN THE UNIT

    Unit 2, Example 2.4 takes the sample \(3, 5, 7, 11, 14\) and the divisor-\(n\) variance \(\hat\theta = 16\), computes the five leave-one-out values \(12.1875,\ 17.1875,\ 19.6875,\ 17.1875,\ 8.75\) with mean \(15\), and obtains

    \[ \widehat{\text{bias}} = 4(15 - 16) = -4, \qquad \hat\theta_{\text{jack}} = 16 + 4 = 20 = s^{2}, \]

    recovering the divisor \(n-1\) exactly. The pseudo-values \(31.25,\ 11.25,\ 1.25,\ 11.25,\ 45.00\) give \(\widehat{SE}_{\text{jack}} = 7.925434\).

    In the examination, set the work out as a table with one row per omitted observation, and always state the pseudo-values — the standard error comes from them and not from the leave-one-out values directly.

    Practical 2 — Bootstrap Estimates

    WORKED IN FULL IN THE UNIT

    Unit 2, Example 2.5 enumerates all \(3^{3} = 27\) resamples of the sample \(2, 5, 11\) rather than simulating, so the answer is exact and reproducible in an examination. It obtains a bootstrap mean of \(6.000000\) (equal to \(\bar x\), so zero estimated bias) and

    \[ \operatorname{Var}^{*}\left(\bar X^{*}\right) = 4.666667 = \frac{s_n^{2}}{n}, \qquad \widehat{SE}_{\text{boot}} = 2.160247, \]

    against the classical \(\sqrt{s^{2}/n} = 2.645751\). The two differ by exactly \(\sqrt{(n-1)/n}\).

    A practical warning. \(n^{n}\) resamples is \(27\) at \(n = 3\) but \(10^{10}\) at \(n = 10\). Enumeration is an examination device for small \(n\); for real data the resamples are drawn at random, and \(B = 1000\) or more is used with the seed recorded.

    Practical 3 — MLE by the Method of Scoring, Cauchy Location

    WHY THIS PARTICULAR PROBLEM IS SET

    For the Cauchy there is no closed-form MLE and no useful moment estimator — Distribution Theory, Unit 1 proves the mean does not exist, so the sample mean estimates nothing. The likelihood equation must be solved numerically, and this practical is where that is learned.

    Given. A sample of \(n = 7\) from Cauchy\((\theta, 1)\):

    \[ -1.94,\quad -0.44,\quad 0.10,\quad 0.72,\quad 1.35,\quad 2.18,\quad 3.91. \]

    Step 1 — the log-likelihood and the score. With density \(\dfrac{1}{\pi\left[1 + (x-\theta)^{2}\right]}\),

    \[ \ln L = -n\ln\pi - \sum_{i=1}^{n}\ln\!\left[1 + (x_i - \theta)^{2}\right], \qquad U(\theta) = \frac{\partial \ln L}{\partial\theta} = \sum_{i=1}^{n}\frac{2(x_i - \theta)}{1 + (x_i - \theta)^{2}}. \]

    Step 2 — the information. For the Cauchy location family, \(I(\theta) = \tfrac12\) per observation, so the total is

    \[ n I(\theta) = \frac{7}{2} = 3.5, \]

    a constant — which is what makes scoring simpler than Newton–Raphson here: the divisor never has to be recomputed.

    Step 3 — the iteration.

    \[ \theta^{(k+1)} = \theta^{(k)} + \frac{U\left(\theta^{(k)}\right)}{n I(\theta)}. \]

    Step 4 — a sensible starting value. The sample median, which is \(0.72\), the fourth of seven ordered values. Never start from the sample mean \(0.840000\): for a Cauchy it is not consistent for anything, and a poor start can send the iteration to a local maximum, of which the Cauchy likelihood can have several.

    Step 5 — run it.

    \(k\)\(\theta^{(k)}\)\(U(\theta^{(k)})\)step \(U/3.5\)\(\theta^{(k+1)}\)
    00.720000−0.138266−0.0395050.680495
    10.680495−0.036366−0.0103900.670105
    20.670105−0.009459−0.0027030.667402
    30.667402−0.002453−0.0007010.666701
    40.666701−0.000635−0.0001810.666520

    Step 6 — read the convergence. Each step is about \(0.26\) times the previous one, so the error falls by roughly a quarter per iteration — linear convergence, which is what scoring gives (Newton–Raphson would be quadratic but needs the observed information recomputed each time). After five iterations \(\hat\theta = 0.666520\) and the score is \(-1.66 \times 10^{-4}\), effectively zero.

    Step 7 — the standard error and an interval. By the asymptotic normality of the MLE from Unit 2,

    \[ \widehat{SE} = \frac{1}{\sqrt{n I(\theta)}} = \sqrt{\frac{2}{n}} = \sqrt{\frac{2}{7}} = 0.5345225, \] \[ 0.666520 \pm 1.96 \times 0.5345225 = 0.666520 \pm 1.0476641 = (-0.381144,\ 1.714184). \]

    Interpretation. The MLE \(0.6665\) sits below the sample mean \(0.8400\), which the single large observation \(3.91\) has dragged upwards; the likelihood downweights it automatically, because a Cauchy expects occasional extreme values. The interval is very wide for seven observations — \(\sqrt{2/n}\) falls only as \(n^{-1/2}\), and the Cauchy is an uninformative distribution to sample from.

    Practical 4 — Confidence Limits for a Normal Population

    BOTH PARAMETERS, FROM ONE SAMPLE

    Given. \(n = 16\), \(\bar x = 24.5\), \(s = 3.2\), from \(N(\mu, \sigma^{2})\) with both parameters unknown.

    Step 1 — the standard error.

    \[ \frac{s}{\sqrt n} = \frac{3.2}{4} = 0.8000. \]

    Step 2 — the interval for \(\mu\). The pivot is \((\bar X - \mu)/(S/\sqrt n) \sim t_{15}\), whose two-sided \(5\%\) point is \(t_{15,\,0.025} = 2.131449\). (Check: \(P(|t_{15}| > 2.131449) = 0.050000\).)

    \[ 24.5 \pm 2.131449 \times 0.8 = 24.5 \pm 1.7052 = (22.7948,\ 26.2052). \]

    Step 3 — the interval for \(\sigma^{2}\). The pivot is \((n-1)S^{2}/\sigma^{2} \sim \chi^{2}_{15}\), with \(2.5\%\) points \(6.262\) and \(27.488\). Here \((n-1)s^{2} = 15 \times 10.24 = 153.6\), so

    \[ \left(\frac{153.6}{27.488},\ \frac{153.6}{6.262}\right) = (5.5879,\ 24.5289). \]

    Step 4 — the interval for \(\sigma\). Take square roots, which is legitimate because the transformation is monotone:

    \[ \left(\sqrt{5.5879},\ \sqrt{24.5289}\right) = (2.3639,\ 4.9527). \]

    Interpretation. The interval for \(\mu\) is symmetric and narrow; the one for \(\sigma\) is neither, running from \(0.74\) to \(1.55\) times the estimate \(s = 3.2\). Sixteen observations locate a mean well and a standard deviation poorly, and any report that quotes \(s\) without an interval is hiding that.

    Practical 5 — Large-Sample Confidence Limits

    THE COMMON METHOD

    All three cases use the asymptotic normality of the MLE from Unit 2:

    \[ \hat\theta \ \dot\sim\ N\!\left(\theta,\ \frac{1}{n I(\theta)}\right) \;\Longrightarrow\; \hat\theta \pm 1.96\,\widehat{SE}, \qquad \widehat{SE} = \frac{1}{\sqrt{n I(\hat\theta)}}, \]

    with the information evaluated at the estimate because \(\theta\) is unknown. The whole method is: write down \(I(\theta)\), substitute \(\hat\theta\), take the reciprocal square root.

    THE THREE CASES

    (a) Binomial. \(x = 88\) successes in \(n = 400\) trials.

    \[ \hat p = \frac{88}{400} = 0.22, \qquad I(p) = \frac{1}{p(1-p)}, \qquad \widehat{SE} = \sqrt{\frac{\hat p(1 - \hat p)}{n}} = \sqrt{\frac{0.22 \times 0.78}{400}}. \]

    The numerator is \(0.1716\), so \(\widehat{SE} = \sqrt{0.000429} = 0.020712\) and

    \[ 0.22 \pm 1.96 \times 0.020712 = (0.179404,\ 0.260596). \]

    (b) Poisson. \(132\) events observed over \(50\) units of exposure.

    \[ \hat\lambda = \frac{132}{50} = 2.64, \qquad I(\lambda) = \frac{1}{\lambda}, \qquad \widehat{SE} = \sqrt{\frac{\hat\lambda}{n}} = \sqrt{\frac{2.64}{50}} = \sqrt{0.0528} = 0.2297825, \] \[ 2.64 \pm 1.96 \times 0.2297825 = 2.64 \pm 0.4503737 = (2.189626,\ 3.090374). \]

    (c) Exponential. \(n = 100\), \(\bar x = 4.8\).

    \[ \hat\theta = \frac{1}{\bar x} = 0.2083333, \qquad I(\theta) = \frac{1}{\theta^{2}}, \qquad \widehat{SE} = \frac{\hat\theta}{\sqrt n} = \frac{0.2083333}{10} = 0.0208333, \] \[ 0.2083333 \pm 1.96 \times 0.0208333 = 0.2083333 \pm 0.0408333 = (0.167500,\ 0.249167). \]

    A check worth doing, and what it reveals. The mean \(1/\theta\) can be handled either way. Directly, \(\widehat{SE}(\bar X) = \bar x/\sqrt n = 0.48\), giving

    \[ 4.8 \pm 1.96 \times 0.48 = (3.859200,\ 5.740800). \]

    Inverting that interval and reversing the endpoints gives \((0.174192,\ 0.259121)\) for \(\theta\) — not the same as the interval in (c), which was \((0.167500,\ 0.249167)\).

    Interpretation. The discrepancy is real and instructive. A confidence interval is not invariant under a non-linear transformation: building it on the \(\theta\) scale and building it on the \(1/\theta\) scale give different answers, because the normal approximation is being made at different places. Both are valid to the same asymptotic order, and they agree as \(n\) grows — here they overlap over most of their length. The point estimate is invariant, by property (M1) of the MLE in Unit 2; the interval is not. Which scale to work on is decided by where the normal approximation is better, and for a positive parameter that is usually the log scale.

    THE SAME FIVE PRACTICALS IN R, AS A CHECK 
    ## 1 -- jackknife
x <- c(3, 5, 7, 11, 14); n <- length(x)
biased_var <- function(v) mean((v - mean(v))^2)
th <- biased_var(x)
loo <- sapply(seq_len(n), function(i) biased_var(x[-i]))
ps  <- n * th - (n - 1) * loo            # pseudo-values
c(estimate = mean(ps), se = sd(ps) / sqrt(n))
#> estimate 20.000000   se 7.925434
var(x)                                    # 20 -- the jackknife recovered it

## 2 -- bootstrap by complete enumeration
s <- c(2, 5, 11)
g <- expand.grid(s, s, s)
bm <- rowMeans(g)
c(mean = mean(bm), var = mean((bm - mean(bm))^2), se = sqrt(mean((bm - mean(bm))^2)))
#> mean 6.000000   var 4.666667   se 2.160247

## 3 -- Fisher scoring for the Cauchy location
y <- c(-1.94, -0.44, 0.10, 0.72, 1.35, 2.18, 3.91)
score <- function(t) sum(2 * (y - t) / (1 + (y - t)^2))
th <- median(y)                           # NOT mean(y)
for (k in 1:5) th <- th + score(th) / (length(y) / 2)
c(mle = th, score = score(th), se = sqrt(2 / length(y)))
#> mle 0.666520   score -1.66e-04   se 0.534522

## 4 -- normal confidence limits
nn <- 16; xb <- 24.5; s4 <- 3.2
xb + c(-1, 1) * qt(0.975, nn - 1) * s4 / sqrt(nn)        #> 22.7948 26.2052
(nn - 1) * s4^2 / qchisq(c(0.975, 0.025), nn - 1)        #>  5.5879 24.5289

## 5 -- large-sample limits
ph <- 88/400;  ph + c(-1,1)*1.96*sqrt(ph*(1-ph)/400)     #> 0.179404 0.260596
lh <- 132/50;  lh + c(-1,1)*1.96*sqrt(lh/50)             #> 2.189626 3.090374
tb <- 1/4.8;   tb + c(-1,1)*1.96*tb/sqrt(100)            #> 0.167500 0.249167

    What the Practical Record Should Contain

    FOR EACH EXPERIMENT
    1. The aim and the data as given.
    2. The estimator or pivot, written down before any number is computed, with the distribution it follows and why.
    3. Every intermediate quantity — leave-one-out values, pseudo-values, each iteration of the scoring method, the standard error before the interval.
    4. An independent check: the jackknife against \(s^{2}\), the bootstrap against \(\sqrt{s_n^{2}/n}\), the final score against zero, the interval's coverage against the table.
    5. The conclusion in words, including what the width of an interval says about how much the data have determined.
