The 4 validator errors that remain are:

### 2.2 Fixes

- **Formulas on phones** (`assets/site-base.css`). Below 720 px, an inline formula wider than the
  column scrolls in its own box instead of pushing the whole page sideways. This one rule fixed 114
  of the 120 pages.
- **₹ in TeX.** MathJax's font has no rupee glyph, so `₹` inside `\( … \)` became "Math input error".
  It is now written `\text{₹}`. `tools/check_no_raw_tex.py` fails on a bare ₹ in maths.
- **Set braces in Markdown.** The `attr_list` extension read `{E}` at a line end as an attribute
  block and deleted it, so rules like "{B,C} → {E}" lost their consequent. The extension is off, and
  `build_site.py` probes set notation on every build.
- **Bare `<`.** 98 cases of text like `0 < x` were escaped. Inline code that contained tags (for
  example `` `<div>` `` inside Markdown) is now escaped by the generator. Seven stray `</p>` tags were
  removed. `tools/check_markup.py` fails on any bare `<`.
- **Sitemap against robots.txt.** `tools/build_sitemap.py` builds both from one list, and fails if a
  sitemap URL is disallowed. The 16 lab demos left the sitemap and lost their canonical tag.
- **og:url.** `tools/check_canonical.py` requires og:url to equal the canonical on every indexed page,
  and writes it when missing.
- **Stray screenshots.** Deleted. `tools/check_published.py` fails on any tracked image that no
  tracked file references.
- **Duplicate titles.** The program-page generator adds the course only to titles two courses share.
  The older R edition's pages carry "(2023 syllabus)", which the menu already used.
  `tools/check_titles.py` fails on any shared title.

Each new check was broken on purpose once and seen to fail, then restored and seen to pass. All of
them run in `tools/build_all.sh` and in CI (`.github/workflows/validate.yml`).

### 2.3 Not checked, and why

- **External links.** The review proxy blocks outside hosts. There are only four external links (the
  CC licence, GitHub Issues, TensorFlow Playground and Teachable Machine), all at stable addresses.
- **Third-party scripts.** These are MathJax (255 pages), Mermaid (2) and jQuery (1 lab demo). There
  are no web fonts and no trackers.

### 3.2 Errors corrected

Each line gives the page, what was wrong, and what it says now.

**Inferential Statistics**
- **unit3 Problem 15:** the roles of x̄ and μ were swapped, and σ = 3 was called "not known". It now
  uses x̄ = 63.5, μ₀ = 64, σ = 3, giving z = −1.67 and −2.36.
- **unit3 Problem 11:** H₁ pointed the wrong way. It is now P₁ > P₂, which agrees with the page's own
  z = +1.35.
- **unit3 Problem 23:** a right-tailed test was said to reject at 5% on z = −2.24. It never can; that
  sentence is gone.
- **unit3 Problems 5 and 17:** "both intervals exclude" the null value, but one interval contains it.
  The pages now explain why a one-tailed test and a two-sided interval can disagree.
- **unit2 binomial MP test:** c = 58 has size 0.067. It is now c = 59, with size 0.044 and power 0.62.
- **unit2 best critical regions:** four cases claimed a sign for the constant that the working does
  not fix. The claims are dropped; the size condition fixes the constant.
- **unit1:** "2X̄ often biased; max Xᵢ is better". 2X̄ is the unbiased one. Max Xᵢ is biased but has
  the smaller MSE.
- **unit4:**

  - Yates' correction was applied because an *observed* count was 3. The expected count is 6, so no
    correction is needed.

- **unit5:**

## 5. Decisions for the owner

None of these was changed.

1. **Six contestable MCQ keys** (`exams/ugc-net/mcqs.html`):
   - **Unit 5 Q50:** an exact test for p = 0.5 uses the binomial, which is option A; the key says C.
   - **Unit 7 Q14:** the random walk's E(Yₜ) = Y₀, so B, unless the stem fixes Y₀ = 0.
   - **Unit 8 Q16:** "All of the above" includes a false "only".
   - **Unit 3 Q39:** Murthy's estimator is not *always* better than Hansen–Hurwitz.
   - **Unit 5 Q41:** A and C are both right.
   - **Unit 2 Q45:** sharing trace, determinant and eigenvalues does not imply similarity.
2. **"H₀ is accepted".** The house style states the null as proven. The textbook convention in India is
   "accepted". Statisticians prefer "not rejected". Choose one for the whole site.
3. **Textbook reproduction.** Inferential Statistics Units 1–3 and Theory of Probability Units 2–3
   reproduce one textbook's problem sets in its order and numbering. They are re-worked and corrected,
   but the order and statements are the book's. Whether to reword or re-order them is a copyright
   judgement.
4. **Published sources.** The site is served straight from the repository, so these are public:
   - `statistics/CLAUDE.md`;
   - `data-science/machine-learning/self-study-notes/CLAUDE.md`, `AUDIT_REPORT.md` and `CHANGELOG.md`;
   - `exams/ugc-net/README.md` and `archive/*.md`;
   - the ~200 Markdown sources beside the generated Data Science pages.

   Keep them public, or move the authoring notes out of the web root.
5. **Semester structure.** `data-science/study-plan.html`, `syllabus-review.html` and
   `syllabus-map.html` are still organised by semester, because they mirror the programme. Keep or
   re-frame.
6. **Practice sets.** About 96 of 153 statistics units have worked examples but nothing for the reader
   to attempt. Whole courses are affected: Economics, Financial Accounting, Econometrics, SQC,
   discrete distributions, linear algebra and MSc probability. This is content work to schedule.
7. **Thin page.** Theoretical Continuous Distributions Unit 1 (Uniform) has 522 words, against a
   median of 1,787 for statistics units. Expanding it is a content decision.
8. **Lab demos.** The 16 `data-science/labs/course-7-web/` pages are raw student web programs. They are
   now out of the sitemap and disallowed in robots.txt. Six of them are wider than a phone and 16 have
   no description. Leave them as they are, or restyle them.
9. **Title and description lengths.** 184 titles exceed 70 characters and 86 descriptions exceed 170
   characters, so search results truncate them. About 60 lab and practice pages share generic
   descriptions. Shortening these changes how every page is named, so it is a naming decision.
10. **Heading levels.** 123 generated Data Science pages go from h2 to h4 for box titles. Screen
    readers show a gap in the outline. Changing it is a generator-wide style change.

## 6. Low-severity items, fixed after the report

The first version of this report listed these as open. At the owner's request they were fixed on
26 September 2026.
- **Repeated equation ids** (`ce6d198`). Inferential Statistics Unit 2 and Theory of Probability
  Units 2 and 3 number each proof from (1), so MathJax gave several equations one id. Each page now
  loads MathJax's `tagformat` extension, which adds a running count to each id. The visible tags are
  unchanged. Duplicate ids in the DOM went from 5 to 0. `tools/check_markup.py` now fails on a page
  that repeats a `\tag` without `tagformat`; the mutation test fails it and the restore passes it.
- **MathJax loader warnings** (`ce6d198`). The 12 UGC NET pages no longer request `ams` and
  `noundefined`, which the bundle already contains; they load only `noerrors`. Console warnings went
  from 24 to 0, with the same formula counts and 0 errors.
- **Inferential Statistics Unit 4, Example 2** (`86879f2`) now shows its 3 × 2 table of 200 voters,
  the expected counts, each cell's contribution (total 8.40), df = 2 and p ≈ 0.015.
- **Unit 3, Problem 4** (`86879f2`) notes that nQ = 3 makes the normal approximation rough. It gives
  the exact binomial tail, P(X ≥ 18) = 0.405, which reaches the same verdict.
- **Machine Learning Unit 2** (`86879f2`) says that 0.0269 is the population SD and that the sample
  SD is 0.0301.
