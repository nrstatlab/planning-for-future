EXPERIMENT 1 -- Descriptive statistics
  n            = 20
  mean         = 70.0500
  median       = 70.0000
  mode         = none (all values unique)
  range        = 48
  var  (n-1)   = 202.8921   <- R's var()
  sd   (n-1)   = 14.2440   <- R's sd()
  var  (n)     = 192.7475   <- population
  sd   (n)     = 13.8834

  cross-checked against the statistics module ✓

  NOTE: R's var() and sd() use n-1. R has no built-in mode();
        the R script defines one, as the syllabus expects.
