Ten images aligned with a table

Gallery — a 2 × 5 arrangement using colspan

The caveat this experiment is really about. The syllabus asks you to align images using a table, which is layout, and HTML5 forbids it. Tables are for tabular data. A screen reader announces "table, 3 rows, 4 columns" to someone who cannot see the images, which helps nobody.

Do it as asked in the exam — then show the modern equivalent below, which is three lines of CSS and is also responsive.

The same gallery with CSS Grid

.gallery { display: grid; gap: 8px;
           grid-template-columns: repeat(auto-fit, minmax(150px, 1fr)); }

auto-fit fits as many columns as will hold 150px and stretches them to fill the row — a complete responsive gallery with no media queries. object-fit: cover makes images of different aspect ratios fill an identical box by cropping rather than stretching.
