# Archive

Material that existed **only on side branches** of the four original repositories —
never on any of their `main` branches, and so not part of the site.

It is kept here for one reason: so that the four source repositories can be
archived or deleted with nothing left behind. Every other file from all four is
in the sections themselves, verified by content hash.

None of this is current. Do not read it as study material.

## About that last one

It is the **predecessor** of the notes now at
[`data-science-major/machine-learning/self-study-notes/`](../data-science-major/machine-learning/self-study-notes/),
which split the same material across 16 pages and grew it from 20 algorithms to
23. `Machine-Learning`'s `main` branch replaced this file with a redirect stub
pointing at the new site, so its removal was deliberate, not accidental.

The current notes supersede it in every respect. It is here only so the deletion
of the source repository loses nothing.

## What an archive cannot hold

Deleting the four repositories would also discard things that are not files:

- **Commit history** — 47 commits on `Data-Science-Major-2025` alone. This
  repository has a handful, holding final states rather than how they were reached.
- **Their GitHub Pages URLs** — `nrstatlab.github.io/Statistics-Major/` and the
  other three. Any existing link or bookmark to them would break.
- **Issues, pull requests, releases and discussions**, if any exist.

Archiving a repository instead of deleting it keeps all of the above, is
reversible, costs nothing, and still removes it from view.
