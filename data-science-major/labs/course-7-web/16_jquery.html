This page loads jQuery from a CDN. With no network it falls back to 16_jquery_native.js, which does exactly the same things with no library — compare the two.

Effects

Effects queue per element: each waits for the previous to finish. That is why they chain so readably — and why a hover effect without .stop() keeps animating long after the pointer has left, because every hover queued another animation.

Chaining

$("#msg").removeClass("error").addClass("success")
         .text("Saved successfully").fadeIn(300);

Getters break the chain. .text() with no argument returns a string, and a string has no .css(). Only setters return the jQuery object.
